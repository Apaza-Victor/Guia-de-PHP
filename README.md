# PHPMaster — Guia Completa de PHP

> Aprende PHP desde cero hasta nivel profesional. Todo en un solo lugar, actualizado para PHP 8+.

## Contenido

### PHP Basico
- Introduccion a PHP
- Conceptos fundamentales
- Variables y tipos de datos
- Operadores
- Condicionales (if/else, switch)
- Bucles (for, while, do-while, foreach)
- Bucles anidados
- Funciones
- Arrays
- Strings
- Formularios HTML

### Programacion Orientada a Objetos
- POO Fundamentos (clases, herencia, polimorfismo)
- POO Avanzado (interfaces, traits, enums)

### Entornos de Desarrollo
- XAMPP (Apache + MySQL + PHP)
- Laragon (entorno moderno para Windows)

### Servidor y Backend
- Bases de datos MySQL y PDO
- Sesiones y cookies
- Manejo de archivos
- Seguridad web (XSS, CSRF, SQL Injection)

### Temas Avanzados
- Expresiones Regulares (Regex)
- Manejo de errores y excepciones
- POO Avanzada
- APIs y JSON (REST, cURL)
- Composer y Namespaces
- Diagramas y Patrones de Diseno

### Nuevos Modulos
- **PHP 8.x** — Enums, Fibers, Named Arguments, Readonly, Match, Constructor Property Promotion
- **Laravel Intro** — Routing, Blade, Eloquent, Migraciones, Artisan CLI
- **Testing con PHPUnit** — Tests unitarios, de integracion, setUp/tearDown, mocks
- **Docker y Despliegue** — Docker Compose para PHP, CI/CD, hosting, produccion
- **Rendimiento** — OPcache, profiling con Xdebug, caché, lazy loading, optimizacion
- **Git Basico** — Control de versiones para proyectos PHP

## Caracteristicas

- 33 secciones de contenido
- Codigo con resaltado de sintaxis y boton de copiar
- Tema oscuro/claro
- Navegacion responsive con dropdowns
- Iconografia con Lucide Icons
- Diseño moderno con CSS custom

## Tecnologias

- HTML5 + CSS3 (custom properties, grid, flexbox)
- JavaScript vanilla (SPA loader, tabs, code-copy)
- Lucide Icons
- GitHub Pages (deploy automatico)
