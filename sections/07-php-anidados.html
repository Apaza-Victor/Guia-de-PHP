ℹ️ Escenario: tenemos un array de usuarios y queremos clasificarlos y mostrarlos en una tabla HTML con estilos según su estado y rol.
tabla_usuarios.php
<?php
$usuarios = [
    ["nombre" => "Ana",   "rol" => "admin",  "activo" => true,  "edad" => 28],
    ["nombre" => "Luis",  "rol" => "editor", "activo" => false, "edad" => 34],
    ["nombre" => "María", "rol" => "admin",  "activo" => true,  "edad" => 41],
    ["nombre" => "Pedro", "rol" => "lector", "activo" => true,  "edad" => 22],
    ["nombre" => "Sara",  "rol" => "editor", "activo" => false, "edad" => 17],
];

echo "<table border='1'><tr><th>Nombre</th><th>Rol</th><th>Estado</th><th>Grupo edad</th></tr>";

foreach ($usuarios as $u) {

    // Condicional anidado: ícono de rol
    if ($u["rol"] === "admin") {
        $icono = "👑";
    } elseif ($u["rol"] === "editor") {
        $icono = "✏️";
    } else {
        $icono = "👁";
    }

    // Condicional anidado: estado activo + es mayor de edad
    if ($u["activo"]) {
        if ($u["edad"] >= 18) {
            $estado = "✅ Activo";
        } else {
            $estado = "⚠️ Activo (menor)";
        }
    } else {
        $estado = "❌ Inactivo";
    }

    // match anidado: grupo de edad
    $grupoEdad = match(true) {
        $u["edad"] <  18 => "Menor",
        $u["edad"] <  30 => "Joven",
        $u["edad"] <  45 => "Adulto",
        default          => "Senior",
    };

    echo "<tr>";
    echo "  <td>{$u['nombre']}</td>";
    echo "  <td>$icono {$u['rol']}</td>";
    echo "  <td>$estado</td>";
    echo "  <td>$grupoEdad ({$u['edad']} años)</td>";
    echo "</tr>";
}

echo "</table>";
?>
▶ Salida
👑 Ana  →  ✅ Activo  →  Joven (28 años)
✏️ Luis  →  ❌ Inactivo  →  Adulto (34 años)
👑 María  →  ✅ Activo  →  Adulto (41 años)
👁 Pedro  →  ✅ Activo  →  Joven (22 años)
✏️ Sara  →  ⚠️ Activo (menor)  →  Menor (17 años)
ℹ️ Escenario: calcular el total de un carrito aplicando descuentos por cantidad, impuestos por categoría y cupón global.
carrito_anidado.php
<?php
$carrito = [
    ["nombre" => "Laptop",    "cat" => "tech",   "precio" => 1200, "qty" => 1],
    ["nombre" => "Auriculares", "cat" => "tech",   "precio" => 80,   "qty" => 3],
    ["nombre" => "Camiseta",   "cat" => "ropa",   "precio" => 25,   "qty" => 5],
    ["nombre" => "Libro PHP",  "cat" => "libros", "precio" => 45,   "qty" => 2],
];

$cupon      = "DESCUENTO10";
$totalFinal = 0;

foreach ($carrito as $item) {
    $subtotal = $item["precio"] * $item["qty"];

    // 1. Descuento por cantidad (bucle anidado implícito: condición dentro de foreach)
    if ($item["qty"] >= 5) {
        $descQty = 0.15;        // 15% por comprar 5 o más
    } elseif ($item["qty"] >= 3) {
        $descQty = 0.08;        // 8% por comprar 3 o más
    } else {
        $descQty = 0;
    }
    $subtotal *= (1 - $descQty);

    // 2. IVA según categoría (switch anidado dentro del foreach)
    switch ($item["cat"]) {
        case "tech":
            $iva = 0.18;
            break;
        case "ropa":
            $iva = 0.10;
            break;
        case "libros":
            $iva = 0;           // libros exentos
            break;
        default:
            $iva = 0.21;
    }
    $subtotal *= (1 + $iva);

    $totalFinal += $subtotal;

    printf(
        "%-12s x%d  desc:%.0f%%  IVA:%.0f%%  → S/ %.2f\n",
        $item["nombre"], $item["qty"],
        $descQty * 100, $iva * 100, $subtotal
    );
}

// 3. Cupón global (condicional fuera del bucle)
if ($cupon === "DESCUENTO10" && $totalFinal > 200) {
    $totalFinal *= 0.90;
    echo "🎟 Cupón aplicado: -10%\n";
} elseif ($cupon !== "") {
    echo "⚠️ Cupón no válido o compra insuficiente\n";
}

echo "Total: S/ " . number_format($totalFinal, 2);
?>
▶ Salida
Laptop x1 desc:0% IVA:18% → S/ 1416.00
Auriculares x3 desc:8% IVA:18% → S/ 273.89
Camiseta x5 desc:15% IVA:10% → S/ 116.88
Libro PHP x2 desc:0% IVA:0% → S/ 90.00
🎟 Cupón aplicado: -10%
Total: S/ 1,709.77
ℹ️ Escenario: recorrer una matriz bidimensional con for anidado y aplicar condiciones para colorear celdas, dibujar patrones y calcular estadísticas por fila/columna.
matriz_anidada.php
<?php
// Notas de estudiantes: filas = estudiantes, columnas = materias
$notas = [
    "Ana"   => [88, 92, 45, 76],
    "Luis"  => [72, 58, 90, 83],
    "María" => [95, 98, 100, 92],
    "Pedro" => [40, 35, 55, 48],
];
$materias  = ["Matemáticas", "PHP", "BD", "HTML"];
$aprobados = 0;
$suspensos = 0;

// foreach anidado con múltiples condicionales
foreach ($notas as $alumno => $calificaciones) {
    $total     = 0;
    $suspenso  = false;
    $sobresale = true;

    echo "\n📋 $alumno: ";

    // for anidado dentro del foreach: recorrer cada nota
    for ($i = 0; $i < count($calificaciones); $i++) {
        $nota  = $calificaciones[$i];
        $total += $nota;

        // if anidado dentro del for: clasificar nota
        if ($nota < 50) {
            echo "❌$nota ";
            $suspenso  = true;
            $sobresale = false;
        } elseif ($nota < 70) {
            echo "🟡$nota ";
            $sobresale = false;
        } elseif ($nota < 90) {
            echo "🟢$nota ";
        } else {
            echo "⭐$nota ";
        }
    }

    $media = $total / count($calificaciones);

    // if/elseif anidado para resultado final del alumno
    if ($suspenso) {
        if ($media >= 50) {
            echo "→ Recuperación (media: $media)";
        } else {
            echo "→ Suspenso (media: $media)";
            $suspensos++;
        }
    } elseif ($sobresale) {
        echo "→ 🏆 Sobresaliente (media: $media)";
        $aprobados++;
    } else {
        echo "→ Aprobado (media: $media)";
        $aprobados++;
    }
}

echo "\n\n📊 Resumen: $aprobados aprobados, $suspensos suspensos";
?>
▶ Salida
📋 Ana: 🟢88 ⭐92 ❌45 🟢76 → Recuperación (media: 75.25)
📋 Luis: 🟢72 🟡58 ⭐90 🟢83 → Aprobado (media: 75.75)
📋 María: ⭐95 ⭐98 ⭐100 ⭐92 → 🏆 Sobresaliente (media: 96.25)
📋 Pedro: ❌40 ❌35 🟡55 ❌48 → Suspenso (media: 44.5)
📊 Resumen: 2 aprobados, 1 suspensos
ℹ️ Escenario: renderizar un menú de navegación multinivel (hasta 3 niveles) combinando while, foreach y condicionales para marcar el ítem activo y calcular indentación.
menu_multinivel.php
<?php
$menu = [
    ["titulo" => "Inicio",    "url" => "/",         "hijos" => []],
    ["titulo" => "Productos", "url" => "/productos", "hijos" => [
        ["titulo" => "Electrónica", "url" => "/electronica", "hijos" => [
            ["titulo" => "Laptops",  "url" => "/laptops",  "hijos" => []],
            ["titulo" => "Monitores", "url" => "/monitores", "hijos" => []],
        ]],
        ["titulo" => "Ropa", "url" => "/ropa", "hijos" => []],
    ]],
    ["titulo" => "Blog",      "url" => "/blog",      "hijos" => []],
    ["titulo" => "Contacto",  "url" => "/contacto",  "hijos" => []],
];

$urlActual = "/laptops";  // simular la página actual

// Función recursiva que usa foreach + while + condicionales anidados
function renderMenu(array $items, string $urlActual, int $nivel = 0): void {
    $maxNivel = 3;  // máximo de niveles a renderizar

    // while anidado: no superar el nivel máximo
    if ($nivel >= $maxNivel) return;

    $prefijos = ["├─", "│ ├─", "│ │ └─"];
    $iconos   = ["📁", "📂", "📄"];

    foreach ($items as $item) {
        $esActivo  = ($item["url"] === $urlActual);
        $tieneHijos = !empty($item["hijos"]);

        // if anidado: ícono según nivel + si tiene hijos
        if ($tieneHijos) {
            $icono = $nivel === 0 ? "📁" : "📂";
        } else {
            $icono = "📄";
        }

        // if anidado: marcar activo o ancestro del activo
        if ($esActivo) {
            $marca = " ◀ ACTUAL";
        } elseif (str_starts_with($urlActual, $item["url"]) && $item["url"] !== "/") {
            $marca = " ▶ (ancestro)";
        } else {
            $marca = "";
        }

        $prefijo = $prefijos[$nivel] ?? "  ";
        echo "$prefijo $icono {$item['titulo']}$marca\n";

        // Recursión condicional: entrar en hijos solo si los hay
        if ($tieneHijos) {
            renderMenu($item["hijos"], $urlActual, $nivel + 1);
        }
    }
}

echo "🗂 Menú de Navegación\n";
renderMenu($menu, $urlActual);
?>
▶ Salida
🗂 Menú de Navegación
├─ 📁 Inicio
├─ 📁 Productos ▶ (ancestro)
│ ├─ 📂 Electrónica ▶ (ancestro)
│ │ └─ 📄 Laptops ◀ ACTUAL
│ │ └─ 📄 Monitores
│ ├─ 📄 Ropa
├─ 📄 Blog
├─ 📄 Contacto
