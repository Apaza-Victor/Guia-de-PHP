Módulo 5

Sesiones & Cookies

Mantén el estado del usuario entre páginas: login, carrito de compras y preferencias.

1
Sesiones ($_SESSION)
Las sesiones almacenan datos en el servidor vinculados a un ID único enviado al navegador como cookie.
session_start() debe ser la primera línea de cada archivo PHP que use sesiones, antes de cualquier salida HTML.
sesion_basico.php
<?php
session_start();  // SIEMPRE primero — antes de cualquier echo

// Guardar datos en sesión
$_SESSION['usuario_id']  = 42;
$_SESSION['nombre']      = 'Ana García';
$_SESSION['rol']         = 'admin';
$_SESSION['login_en']    = time();

// Leer con isset — evitar errores si no existe
if (isset($_SESSION['nombre'])) {
    echo "Bienvenida, " . htmlspecialchars($_SESSION['nombre']);
}

// Leer con ?? para valor por defecto
$rol = $_SESSION['rol'] ?? 'invitado';

// Ver ID de sesión (es el PHPSESSID enviado como cookie)
echo session_id();

// Eliminar UNA variable de sesión
unset($_SESSION['rol']);

// Eliminar TODAS las variables de sesión
$_SESSION = [];

// Destruir la sesión completamente (logout)
session_destroy();
?>
▶ Salida
Bienvenida, Ana García
session_id(): a3f9b2c1d4e8f7g6h5i4j3k2l1
Cómo funcionan las sesiones
1. session_start() → PHP crea un ID único (ej: abc123...)
2. PHP envía al navegador: Set-Cookie: PHPSESSID=abc123
3. PHP guarda $_SESSION en archivo en el servidor
4. Próxima request → navegador envía Cookie: PHPSESSID=abc123
5. PHP carga los datos de $_SESSION del servidor para ese ID
sesion_config.php
<?php
// Configurar sesión ANTES de session_start()
ini_set('session.cookie_httponly', '1');    // JS no puede leer la cookie
ini_set('session.cookie_secure',   '1');    // solo HTTPS
ini_set('session.cookie_samesite', 'Strict'); // anti-CSRF
ini_set('session.gc_maxlifetime',   3600);    // 1 hora de inactividad
ini_set('session.use_strict_mode',  '1');    // rechaza IDs no generados por PHP

// Alternativamente con session_set_cookie_params()
session_set_cookie_params([
    'lifetime' => 0,          // 0 = hasta cerrar el navegador
    'path'     => '/',
    'secure'   => true,
    'httponly' => true,
    'samesite' => 'Strict',
]);
session_start();

// Expiración de sesión por inactividad
if (isset($_SESSION['ultimo_acceso'])) {
    $inactivo = time() - $_SESSION['ultimo_acceso'];
    if ($inactivo > 1800) {                    // 30 min
        session_destroy();
        header("Location: login.php?msg=expirada");
        exit;
    }
}
$_SESSION['ultimo_acceso'] = time();

// Regenerar ID periódicamente para prevenir session hijacking
if (empty($_SESSION['token_generado']) ||
    time() - $_SESSION['token_generado'] > 300) {    // cada 5 min
    session_regenerate_id(true);
    $_SESSION['token_generado'] = time();
}
?>
▶ Opciones clave
httponly=1 → protege contra robo de sesión por XSS
samesite=Strict → protege contra CSRF
use_strict_mode=1 → previene session fixation
Los mensajes flash son datos en sesión que se muestran una sola vez al usuario (éxito, error, aviso) y se eliminan inmediatamente después de leerlos.
flash_messages.php
<?php
session_start();

// Guardar mensaje flash (antes de redirect)
function flash(string $tipo, string $msg): void {
    $_SESSION['flash'][] = ['tipo' => $tipo, 'msg' => $msg];
}

// Mostrar y eliminar mensajes flash
function mostrarFlash(): void {
    if (empty($_SESSION['flash'])) return;
    foreach ($_SESSION['flash'] as $f) {
        $color = match($f['tipo']) {
            'success' => '#4CAF50',
            'error'   => '#ef5350',
            'warning' => '#ffa726',
            default   => '#42a5f5',
        };
        echo "<div style='color:$color'>"
           . htmlspecialchars($f['msg'], ENT_QUOTES, 'UTF-8')
           . "</div>";
    }
    unset($_SESSION['flash']);  // eliminar tras mostrar
}

// USO en el controlador
flash('success', '✅ Producto guardado correctamente');
flash('error',   '❌ El email ya está registrado');
header('Location: /productos');
exit;

// USO en la vista (después del redirect)
// mostrarFlash();  ← llama al inicio de cada plantilla HTML
?>
▶ Salida tras redirect
Producto guardado correctamente
El email ya está registrado
← Aparecen una vez y desaparecen al recargar
Característica$_SESSION$_COOKIE
Dónde se guardan los datos Servidor (archivo/BD) Navegador del usuario
Duración por defectoMientras el navegador esté abiertoDefinida por el programador
Tamaño máximoSin límite práctico~4 KB por cookie
Seguridad Alta — datos en servidor️ Media — visible/modificable
El usuario puede ver los datos No (solo el ID) Sí (desde las DevTools)
Uso típicoLogin, carrito, datos temporalesTema, idioma, "recuérdame"

Regla práctica: usa $_SESSION para datos de autenticación y sensibles. Usa $_COOKIE solo para preferencias no sensibles del usuario.

procesar_login.php
<?php
session_start();

// 1. Verificar CSRF
if (!hash_equals($_SESSION['csrf'] ?? '', $_POST['_token'] ?? '')) {
    die('Petición no válida');
}

// 2. Validar entrada
$email    = filter_var($_POST['email']    ?? '', FILTER_VALIDATE_EMAIL);
$password = $_POST['password'] ?? '';
if (!$email || strlen($password) < 1) {
    header('Location: login.php?error=1'); exit;
}

// 3. Buscar usuario con sentencia preparada
$stmt = $pdo->prepare("SELECT id, nombre, rol, password_hash FROM usuarios WHERE email = :e AND activo = 1 LIMIT 1");
$stmt->execute([':e' => $email]);
$usuario = $stmt->fetch();

// 4. Verificar contraseña
if (!$usuario || !password_verify($password, $usuario['password_hash'])) {
    header('Location: login.php?error=1'); exit;
}

// 5. Login exitoso — regenerar ID (previene session fixation)
session_regenerate_id(true);
$_SESSION['usuario_id'] = $usuario['id'];
$_SESSION['nombre']     = $usuario['nombre'];
$_SESSION['rol']        = $usuario['rol'];
$_SESSION['login_en']   = time();

// 6. Rehash si el algoritmo mejoró
if (password_needs_rehash($usuario['password_hash'], PASSWORD_DEFAULT)) {
    $nuevo = password_hash($password, PASSWORD_DEFAULT);
    $pdo->prepare("UPDATE usuarios SET password_hash=? WHERE id=?")->execute([$nuevo,$usuario['id']]);
}

header('Location: dashboard.php'); exit;
?>
Para crear el hash al registrar: password_hash($password, PASSWORD_DEFAULT)
auth.php — incluir en páginas protegidas
<?php
session_start();

function requiereLogin(string $redirect = 'login.php'): void {
    if (!isset($_SESSION['usuario_id'])) {
        header("Location: $redirect");
        exit;
    }
}

function requiereRol(string ...$roles): void {
    requiereLogin();
    if (!in_array($_SESSION['rol'] ?? '', $roles, true)) {
        http_response_code(403);
        die("❌ Acceso denegado");
    }
}

function usuarioActual(): array {
    return [
        'id'     => $_SESSION['usuario_id'] ?? null,
        'nombre' => $_SESSION['nombre']     ?? '',
        'rol'    => $_SESSION['rol']        ?? 'invitado',
    ];
}
?>

<!-- dashboard.php -->
<?php
require 'auth.php';
requiereLogin();
$user = usuarioActual();
echo "Hola, " . htmlspecialchars($user['nombre']);
?>

<!-- admin.php — solo admins -->
<?php
require 'auth.php';
requiereRol('admin', 'superadmin');
echo "Panel de administración";
?>
logout_seguro.php
<?php
session_start();

// Logout seguro — 4 pasos obligatorios
function logout(): void {
    // 1. Limpiar array de sesión
    $_SESSION = [];

    // 2. Eliminar cookie de sesión del navegador
    if (ini_get('session.use_cookies')) {
        $params = session_get_cookie_params();
        setcookie(session_name(), '', [
            'expires'  => time() - 42000,
            'path'     => $params['path'],
            'secure'   => $params['secure'],
            'httponly' => $params['httponly'],
        ]);
    }

    // 3. Destruir la sesión en el servidor
    session_destroy();

    // 4. Redirigir al login
    header('Location: /login.php');
    exit;
}

logout();
?>
▶ Los 4 pasos del logout seguro
1. $_SESSION = [] → limpiar datos en memoria
2. setcookie(..., time()-42000) → eliminar cookie del navegador
3. session_destroy() → eliminar archivo de sesión del servidor
4. header('Location: /login') → redirigir

Cookies ($_COOKIE)
Datos guardados en el navegador del usuario. Útiles para preferencias, "recordarme" y analytics.
cookies_basico.php
<?php
// setcookie() DEBE llamarse antes de cualquier salida HTML

// Sintaxis moderna (PHP 7.3+) — array de opciones
setcookie('tema', 'oscuro', [
    'expires'  => time() + 30 * 86400,  // 30 días
    'path'     => '/',                   // toda la web
    'secure'   => true,                  // solo HTTPS
    'httponly' => false,                 // JS puede leer (para tema)
    'samesite' => 'Lax',
]);

// Leer cookie (disponible en la SIGUIENTE request)
$tema = $_COOKIE['tema'] ?? 'claro';  // ?? valor por defecto
echo "Tema actual: " . htmlspecialchars($tema);

// Múltiples cookies
setcookie('idioma', 'es',     ['expires' => time() + 365 * 86400]);
setcookie('moneda', 'PEN',   ['expires' => time() + 365 * 86400]);

// Eliminar cookie (expires en el pasado)
setcookie('tema', '', ['expires' => time() - 3600, 'path' => '/']);
unset($_COOKIE['tema']);  // también de la variable local
?>
▶ Ciclo de vida de una cookie
setcookie() → HTTP: Set-Cookie: tema=oscuro; Max-Age=2592000; Path=/
Siguiente request → HTTP: Cookie: tema=oscuro
PHP puede leerla en $_COOKIE['tema']
cookies_seguridad.php
<?php
// El usuario PUEDE modificar cookies desde el navegador
// NUNCA confíes en el valor de una cookie sin validar

// ❌ VULNERABLE — el usuario puede cambiar su rol en la cookie
$rol = $_COOKIE['rol'];  // podría ser "admin" aunque sea "lector"

// ✅ Almacenar tokens firmados en cookies — no datos sensibles
function crearCookieSegura(string $nombre, string $valor): void {
    // Firma el valor con una clave secreta
    $clave  = getenv('APP_SECRET');
    $firma  = hash_hmac('sha256', $valor, $clave);
    setcookie($nombre, $valor . '.' . $firma, [
        'expires'  => time() + 30 * 86400,
        'httponly' => true,
        'secure'   => true,
        'samesite' => 'Strict',
    ]);
}

function leerCookieSegura(string $nombre): ?string {
    if (!isset($_COOKIE[$nombre])) return null;
    [$valor, $firma] = explode('.', $_COOKIE[$nombre], 2);
    $clave           = getenv('APP_SECRET');
    $firmaEsperada   = hash_hmac('sha256', $valor, $clave);
    return hash_equals($firmaEsperada, $firma) ? $valor : null;
}
?>
OpciónValor recomendadoEfecto
securetrueSolo se envía por HTTPS
httponlytrueJavaScript no puede acceder
samesite'Strict'No se envía en peticiones cross-site (anti-CSRF)

recordarme.php
<?php
// "Recuérdame" — mantener sesión entre visitas
// NUNCA guardar el ID de usuario directamente en la cookie
// Usar un token aleatorio en BD

// AL HACER LOGIN con "recuérdame"
if (isset($_POST['recordarme']) && $loginExitoso) {
    $token    = bin2hex(random_bytes(32));   // token único y aleatorio
    $selector = bin2hex(random_bytes(6));    // para buscar en BD
    $expira   = time() + 30 * 86400;         // 30 días

    // Guardar hash del token en BD (no el token en claro)
    $pdo->prepare("INSERT INTO remember_tokens (selector, token_hash, usuario_id, expira) VALUES (?,?,?,?)")
       ->execute([$selector, hash('sha256',$token), $usuarioId, date('Y-m-d H:i:s',$expira)]);

    // Guardar selector:token en cookie
    setcookie('remember', "$selector:$token", [
        'expires' => $expira, 'httponly' => true,
        'secure'  => true,  'samesite' => 'Strict',
    ]);
}

// AL VISITAR LA WEB (sin sesión activa)
if (!isset($_SESSION['usuario_id']) && isset($_COOKIE['remember'])) {
    [$selector, $token] = explode(':', $_COOKIE['remember'], 2);

    $row = $pdo->prepare("SELECT * FROM remember_tokens WHERE selector=? AND expira > NOW()");
    $row->execute([$selector]);
    $registro = $row->fetch();

    if ($registro && hash_equals($registro['token_hash'], hash('sha256',$token))) {
        session_regenerate_id(true);
        $_SESSION['usuario_id'] = $registro['usuario_id'];
        // cargar resto de datos del usuario desde BD
    }
}
?>
Esta implementación es segura porque: el token está hasheado en BD, se usa hash_equals para comparación segura, y un selector separado permite búsquedas rápidas sin exponer el token real.
