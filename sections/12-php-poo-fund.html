Fundamentos de POO — Conceptos Base
Clase · objeto · atributo · método · encapsulamiento · herencia · polimorfismo · abstracción.
️ Los 4 pilares de la POO
Encapsulamiento
Ocultar los detalles internos de un objeto y exponer solo lo necesario. Los atributos se protegen con private o protected y se acceden mediante métodos (getters/setters).
Como una cápsula: lo que hay dentro está protegido.
Herencia
Una clase hija hereda atributos y métodos de una clase padre, pudiendo añadir o sobrescribir funcionalidad. Evita duplicar código.
Como la herencia biológica: los hijos heredan rasgos de los padres.
Polimorfismo
El mismo método puede comportarse de manera diferente según el objeto que lo ejecute. Permite tratar distintos objetos con la misma interfaz.
Como un botón de "reproducir": en música suena audio, en vídeo muestra frames.
Abstracción
Mostrar solo las características esenciales de un objeto, ocultando la complejidad interna. Se logra con clases abstractas e interfaces.
Como conducir un coche: usas el volante sin saber cómo funciona el motor.

Encapsulamiento: los datos internos se protegen con private. Solo se accede a ellos mediante métodos públicos controlados (getters y setters), lo que evita estados inválidos.
encapsulamiento.php
<?php
class CuentaBancaria {
    // private: solo accesible dentro de la clase
    private float  $saldo   = 0;
    private string $titular;
    private array  $movimientos = [];

    public function __construct(string $titular, float $saldoInicial = 0) {
        $this->titular = $titular;
        if ($saldoInicial > 0) $this->saldo = $saldoInicial;
    }

    // GETTER — solo lectura del saldo
    public function getSaldo(): float {
        return $this->saldo;
    }

    // Método con lógica de negocio — no setter directo
    public function depositar(float $monto): void {
        if ($monto <= 0) throw new InvalidArgumentException("Monto debe ser positivo");
        $this->saldo += $monto;
        $this->movimientos[] = ["tipo" => "+", "monto" => $monto];
    }

    public function retirar(float $monto): bool {
        if ($monto <= 0)              throw new InvalidArgumentException("Monto inválido");
        if ($monto > $this->saldo)   return false;  // saldo insuficiente
        $this->saldo -= $monto;
        $this->movimientos[] = ["tipo" => "-", "monto" => $monto];
        return true;
    }

    public function resumen(): string {
        return sprintf("%s — Saldo: S/ %.2f (%d movimientos)",
            $this->titular, $this->saldo, count($this->movimientos)
        );
    }
}

$cuenta = new CuentaBancaria("Ana García", 500);
$cuenta->depositar(200);
$cuenta->retirar(100);
echo $cuenta->resumen();  // Ana García — Saldo: S/ 600.00 (2 movimientos)

// ❌ Esto NO se puede — $saldo es private
// $cuenta->saldo = -9999;  // Error fatal
// $cuenta->saldo;          // Error fatal
?>
▶ Salida
Ana García — Saldo: S/ 600.00 (2 movimientos)
$cuenta->saldo = -9999 → Fatal error: Cannot access private property

Herencia: una clase hija (extends) recibe todos los atributos y métodos public y protected del padre. Puede añadir los suyos propios y sobrescribir los heredados.
herencia.php
<?php
// CLASE PADRE
class Vehiculo {
    public function __construct(
        protected string $marca,
        protected int    $anio
    ) {}

    public function arrancar(): string {
        return "🔑 {$this->marca} arrancando...";
    }

    public function info(): string {  // método a sobrescribir
        return "{$this->marca} ({$this->anio})";
    }
}

// CLASE HIJA — hereda todo de Vehiculo
class Coche extends Vehiculo {
    public function __construct(
        string $marca, int $anio,
        private int $puertas = 4
    ) {
        parent::__construct($marca, $anio);  // llama al constructor padre
    }

    // OVERRIDE — sobrescribe el método del padre
    public function info(): string {
        return parent::info() . " | {$this->puertas} puertas";
    }

    public function acelerar(): string { // método nuevo
        return "🚗 ¡Acelerando!";
    }
}

class Moto extends Vehiculo {
    public function info(): string {
        return parent::info() . " | 🏍 Moto";
    }
}

$c = new Coche("Toyota", 2024);
$m = new Moto("Honda", 2023);

echo $c->arrancar();  // heredado del padre
echo $c->info();      // sobrescrito → Toyota (2024) | 4 puertas
echo $m->info();      // Honda (2023) | 🏍 Moto
?>
▶ Salida
Toyota arrancando...
Toyota (2024) | 4 puertas
Honda (2023) | Moto
Polimorfismo: distintos objetos responden al mismo mensaje (llamada de método) de formas distintas. Permite escribir código genérico que funciona con múltiples tipos.
polimorfismo.php
<?php
// La misma interfaz (hablar) → comportamientos distintos
abstract class Animal {
    public function __construct(protected string $nombre) {}
    abstract public function hablar(): string;  // cada hijo implementa
    public function presentarse(): string {
        return "Soy {$this->nombre} y digo: " . $this->hablar();
    }
}

class Perro  extends Animal {
    public function hablar(): string { return "¡Guau!"; }
}
class Gato   extends Animal {
    public function hablar(): string { return "¡Miau!"; }
}
class Pato   extends Animal {
    public function hablar(): string { return "¡Cuac!"; }
}

// POLIMORFISMO: mismo código, comportamiento diferente según el objeto
$animales = [
    new Perro("Rex"),
    new Gato("Michi"),
    new Pato("Donald"),
];

// El mismo foreach llama al mismo método en cada objeto
// pero cada uno responde diferente → POLIMORFISMO
foreach ($animales as $animal) {
    echo $animal->presentarse() . "<br>";
}

// Type hint con clase padre — acepta cualquier subclase
function hacerHablar(Animal $a): void {
    echo "🐾 " . $a->hablar() . "<br>";
}

hacerHablar(new Perro("Lassie"));   // 🐾 ¡Guau!
hacerHablar(new Gato("Garfield"));  // 🐾 ¡Miau!
?>
▶ Salida — mismo método, distintos comportamientos
Soy Rex y digo: ¡Guau!
Soy Michi y digo: ¡Miau!
Soy Donald y digo: ¡Cuac!
El polimorfismo permite añadir un new Loro("Perico") sin modificar el foreach ni la función hacerHablar(). Eso es código abierto a extensión, cerrado a modificación (principio Open/Closed).
Abstracción: definir qué debe hacer una clase sin especificar cómo. Con clases abstractas e interfaces definimos contratos que las subclases deben cumplir.
abstraccion.php
<?php
// CLASE ABSTRACTA: define qué deben hacer las subclases
// No se puede instanciar directamente
abstract class FormaPago {
    abstract public function pagar(float $monto): bool;
    abstract public function nombre(): string;

    // Método concreto compartido por todas
    public function registrarPago(float $monto): void {
        if ($this->pagar($monto)) {
            echo "✅ Pago de S/$monto con {$this->nombre()} registrado<br>";
        } else {
            echo "❌ Pago fallido con {$this->nombre()}<br>";
        }
    }
}

// Cada subclase implementa el QUÉ a su manera
class Tarjeta extends FormaPago {
    public function __construct(private string $numero) {}
    public function pagar(float $monto): bool {
        echo "💳 Cargando S/$monto a tarjeta ****{$this->numero}<br>";
        return true;
    }
    public function nombre(): string { return "Tarjeta"; }
}

class Yape extends FormaPago {
    public function __construct(private string $telefono) {}
    public function pagar(float $monto): bool {
        echo "📱 Yapiendo S/$monto al {$this->telefono}<br>";
        return true;
    }
    public function nombre(): string { return "Yape"; }
}

class Efectivo extends FormaPago {
    public function __construct(private float $disponible) {}
    public function pagar(float $monto): bool {
        return $this->disponible >= $monto;  // puede fallar
    }
    public function nombre(): string { return "Efectivo"; }
}

// ❌ Esto NO se puede — FormaPago es abstracta
// $fp = new FormaPago();  // Fatal error

// ✅ Uso polimórfico — el código no sabe qué tipo de pago es
function procesarOrden(FormaPago $metodo, float $total): void {
    echo "🛒 Procesando orden de S/$total<br>";
    $metodo->registrarPago($total);
}

procesarOrden(new Tarjeta("1234"),  299.90);
procesarOrden(new Yape("987654321"), 150.00);
procesarOrden(new Efectivo(50),       299.90);
?>
▶ Salida
Cargando S/299.9 a tarjeta ****1234
Pago de S/299.9 con Tarjeta registrado
Yapiendo S/150 al 987654321
Pago de S/150 con Yape registrado
Pago fallido con Efectivo (solo tenía S/50)
