¿Qué es XAMPP?
Paquete all-in-one: Apache + MySQL/MariaDB + PHP + Perl
XAMPP es gratuito y multiplataforma (Windows, Linux, Mac). Es el estándar para aprender PHP de forma local.

Instalación paso a paso
Guía para Windows (proceso similar en Mac y Linux)
  1. Descarga XAMPP desde apachefriends.org y selecciona la versión de PHP que necesitas (recomendado PHP 8.x).
  2. Ejecuta el instalador como administrador. Selecciona al menos: Apache, MySQL, PHP y phpMyAdmin.
  3. Instala en C:\xampp\ (evita rutas con espacios o caracteres especiales).
  4. Abre el XAMPP Control Panel y pulsa Start en Apache y MySQL.
  5. Abre tu navegador y ve a http://localhost — verás la pantalla de bienvenida de XAMPP.
  6. Tu carpeta de proyectos es C:\xampp\htdocs\. Crea una subcarpeta para cada proyecto.
  7. Accede a tu proyecto en http://localhost/mi-proyecto/
Si el puerto 80 está ocupado (por Skype o IIS), cambia el puerto de Apache en su configuración a 8080 y accede via http://localhost:8080.
