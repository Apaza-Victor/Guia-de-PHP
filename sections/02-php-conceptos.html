Conceptos Fundamentales de Programación
Algoritmo · variable · función · paradigmas · tipos de datos · lógica · memoria · buenas prácticas.
Algoritmo
Secuencia de pasos finita, ordenada y precisa para resolver un problema. Independiente del lenguaje.
Receta de cocina = algoritmo. PHP = idioma para escribirlo.
Programa
Algoritmo escrito en un lenguaje de programación que una máquina puede ejecutar.
Algoritmo → lo piensas. Programa → lo escribes en código.
Variable
Espacio en memoria con un nombre y un valor que puede cambiar durante la ejecución.
Caja etiquetada: $edad = 25 — la caja se llama "edad".
Constante
Como una variable pero su valor no cambia durante la ejecución. Se define una vez y no se puede modificar.
define('PI', 3.14159) o const MAX = 100
⚙️
Función
Bloque de código reutilizable con nombre. Recibe parámetros, ejecuta una tarea y puede retornar un resultado.
Máquina: metes datos (parámetros) → sale un resultado (retorno).
Biblioteca / Librería
Colección de funciones y clases ya escritas que puedes usar en tu programa sin tener que crearlas desde cero.
Composer instala librerías. PHP ya incluye muchas: math, string, array...
Parámetro vs Argumento
Parámetro: variable en la definición de la función. Argumento: valor real que se pasa al llamarla.
function suma($a, $b) → $a y $b son parámetros. suma(3, 5) → 3 y 5 son argumentos.
↩️
Valor de retorno
Dato que una función devuelve al código que la llamó usando return. Sin return, devuelve null.
Una función puede retornar cualquier tipo: int, string, array, objeto...
conceptos_basicos.php
<?php
// VARIABLE — su valor cambia
$precio    = 100;
$descuento = 20;
$precio    = $precio - $descuento;  // cambia a 80

// CONSTANTE — su valor NO cambia
define('IVA', 0.18);
// IVA = 0.30;  ← Error: no se puede reasignar

// FUNCIÓN con parámetros y retorno
function calcularTotal(float $precio, float $descuento = 0): float {
    // $precio y $descuento → PARÁMETROS
    $subtotal = $precio * (1 - $descuento);
    return $subtotal * (1 + IVA);  // VALOR DE RETORNO
}

// 100 y 0.10 → ARGUMENTOS
$total = calcularTotal(100, 0.10);
echo "Total: S/ $total";  // Total: S/ 106.2
?>
Tipo de dato
Clasificación del valor que puede almacenar una variable. Determina qué operaciones se pueden realizar con ella.
Escalares: int, float, string, bool. Compuestos: array, object. Especiales: null, resource.
Tipado dinámico vs estático
Dinámico (PHP por defecto): el tipo se asigna automáticamente según el valor. Estático: debes declarar el tipo explícitamente.
PHP 8 permite tipado estricto con declare(strict_types=1).
Expresión
Cualquier combinación de valores, variables y operadores que produce un resultado.
$a + $b, $x > 0, "hola" . $nombre son expresiones.
Sentencia / Instrucción
Unidad completa de ejecución. En PHP termina con ;. Una sentencia puede contener varias expresiones.
$total = $precio * 1.18; es una sentencia completa.
Operador
Símbolo que realiza una operación sobre uno o más valores (operandos). Hay aritméticos, lógicos, comparación, asignación...
+ - * / % ** aritméticos · && || ! lógicos · == === != !== comparación.
⚡
Casting / Conversión
Convertir un valor de un tipo a otro. Puede ser implícita (PHP lo hace solo) o explícita (tú lo indicas).
Implícita: "5" + 3 = 8. Explícita: (int)"5abc" = 5.
Truthy / Falsy
Valores que se evalúan como true o false en un contexto booleano aunque no sean de tipo bool.
Falsy: 0, "", "0", null, false, []. Todo lo demás es truthy.
Comparación estricta vs laxa
Laxa (==): compara solo el valor, convirtiendo tipos. Estricta (===): compara valor Y tipo.
1 == "1" es true, pero 1 === "1" es false. Usa siempre ===.
logica_datos.php
<?php
// TIPADO DINÁMICO — PHP infiere el tipo
$x = 42;         // int
$x = "hola";   // ahora es string (PHP lo permite)

// TIPADO ESTRICTO — PHP exige el tipo declarado
declare(strict_types=1);
function doble(int $n): int { return $n * 2; }
// doble("3");  ← TypeError con strict_types=1

// EXPRESIONES
$a = 5; $b = 3;
$suma      = $a + $b;         // expresión aritmética → 8
$esMayor   = $a > $b;         // expresión lógica → true
$texto     = "Hola " . "PHP";  // expresión de concatenación → "Hola PHP"

// TRUTHY / FALSY en contexto booleano
$valores = [0, "", "0", null, false, [],  1, "hola", [0], "false"];
foreach ($valores as $v) {
    echo var_export($v, true) . " → " . ($v ? "TRUTHY" : "FALSY") . "<br>";
}
?>
▶ Truthy / Falsy
0, "", "0", null, false, [] → FALSY
1, "hola", [0], "false" → TRUTHY ← ¡"false" como string es truthy!

Una estructura de control es una instrucción que decide qué código se ejecuta y en qué orden. Sin ellas, el programa ejecutaría todas las líneas siempre de arriba a abajo.

1. Secuencia
Instrucciones ejecutadas una tras otra en orden.
Ej: declarar, calcular, mostrar
2. Selección
Decide qué bloque ejecutar según una condición.
Ej: if, else, switch, match
3. Repetición
Repite un bloque mientras se cumpla la condición.
Ej: for, while, do-while, foreach

Imperativo
Le dices al programa CÓMO hacer las cosas, paso a paso. Es el paradigma más básico y natural.
PHP, C, Python básico. El código describe cada instrucción en orden.
Procedural
Imperativo organizado en funciones/procedimientos reutilizables. El código se divide en bloques con nombre.
PHP, C. function calcular() { ... }
Orientado a Objetos (OOP)
Organiza el código en objetos que combinan datos (atributos) y comportamiento (métodos). Basado en el mundo real.
PHP, Java, Python. class Producto { ... }
Funcional
Trata la computación como evaluación de funciones matemáticas puras. Evita el estado mutable y los efectos secundarios.
PHP (parcial), Haskell, Elixir. array_map(fn($x) => $x*2, $arr)
Declarativo
Le dices al programa QUÉ quieres obtener, no cómo conseguirlo. El sistema decide la implementación.
SQL: SELECT * FROM usuarios WHERE activo=1
⚡
Reactivo
El programa reacciona a eventos y flujos de datos asíncronos. Ideal para apps en tiempo real.
JavaScript (RxJS), PHP con ReactPHP. Eventos, streams, websockets.
paradigmas_comparados.php
<?php
// MISMO PROBLEMA: sumar los números pares de un array
$nums = [1, 2, 3, 4, 5, 6, 7, 8];

// ── IMPERATIVO / PROCEDURAL ──────────────────────
// Describes CÓMO hacerlo paso a paso
$suma = 0;
foreach ($nums as $n) {
    if ($n % 2 === 0) $suma += $n;
}
echo $suma;  // 20

// ── FUNCIONAL ────────────────────────────────────
// Describes QUÉ quieres (filtrar + reducir)
$suma = array_sum(
    array_filter($nums, fn($n) => $n % 2 === 0)
);
echo $suma;  // 20 — mismo resultado, diferente enfoque

// ── OOP ──────────────────────────────────────────
// Encapsulas la lógica en un objeto
class Calculadora {
    public function __construct(private array $nums) {}
    public function sumaPares(): int {
        return array_sum(array_filter($this->nums, fn($n) => $n % 2 === 0));
    }
}
echo (new Calculadora($nums))->sumaPares();  // 20
?>

Memoria RAM
Almacenamiento temporal y rápido donde viven las variables mientras el programa se ejecuta. Se libera al terminar.
En PHP, cada request tiene su propia memoria que se limpia al finalizar.
Pila de llamadas (Call Stack)
Estructura que registra qué funciones están en ejecución. Cuando llamas a una función, se apila; cuando retorna, se desapila.
Stack overflow = demasiadas llamadas recursivas sin caso base.
Ámbito (Scope)
Parte del código donde una variable es accesible. PHP tiene ámbito de función, clase y global.
Las funciones NO ven variables globales a menos que uses global $var.
Valor vs Referencia
Por valor: se copia el dato (cambios no afectan al original). Por referencia: se comparte la dirección de memoria.
function f(&$x) — el & indica paso por referencia.
Cliente / Servidor
PHP es lenguaje del servidor. El código se ejecuta en el servidor y devuelve HTML al navegador (cliente).
El usuario nunca ve el código PHP, solo el resultado HTML.
♻️
Garbage Collection
Mecanismo automático que libera memoria de variables que ya no se usan. PHP lo hace por conteo de referencias.
unset($var) libera una variable manualmente.
⚙️
Compilado vs Interpretado
Compilado: el código se traduce a máquina antes de ejecutar (C, Java). Interpretado: se traduce línea a línea en tiempo real (PHP, Python).
PHP usa OPcache para compilar a bytecode y ejecutar más rápido.
Síncrono vs Asíncrono
Síncrono: espera a que cada operación termine antes de continuar. Asíncrono: continúa mientras espera.
PHP tradicional es síncrono. ReactPHP permite asincronía.
scope_referencias.php
<?php
// ÁMBITO (SCOPE)
$global = "Soy global";

function sinScope(): void {
    // ❌ No puede ver $global — ámbito de función
    echo $global;  // Notice: undefined
}

function conScope(): void {
    global $global;  // importar variable global
    echo $global;     // ✅ Soy global
}

// VALOR vs REFERENCIA
$a = 10;
$b = $a;    // copia del VALOR
$b = 99;
echo $a;    // 10 — no cambió

$c = &$a;   // REFERENCIA a la misma dirección
$c = 99;
echo $a;    // 99 — ¡cambió! comparten memoria

// PILA DE LLAMADAS — traza de recursión
function factorial(int $n): int {
    if ($n <= 1) return 1;              // caso base — detiene la pila
    return $n * factorial($n - 1);     // apila factorial(3), (2), (1)
}
// Pila: factorial(4) → factorial(3) → factorial(2) → factorial(1)
//       24          ←      6       ←      2        ←      1
?>
Nombres descriptivos
Variables, funciones y clases con nombres que explican su propósito. El código debe leerse como texto.
$x, $tmp, $data
$precioTotal, $usuarioActivo
DRY — Don't Repeat Yourself
No duplicar lógica. Si copias y pegas código, probablemente necesitas una función o clase.
Si hay que corregir un bug, deberías tocarlo en UN solo lugar.
KISS — Keep It Simple
La solución más simple que funcione es la mejor. No compliques innecesariamente.
Funciones pequeñas, una sola responsabilidad, sin magia.
SRP — Una responsabilidad
Cada función o clase debe tener una sola razón para cambiar. No mezclar lógica de negocio con presentación.
Si la función hace A Y B, sepárala en dos funciones.
Comentarios útiles
Comenta el POR QUÉ, no el qué. El código debe ser tan claro que no necesite explicar lo que hace.
// suma 1 a $i
// compensamos el índice base-0
Principio de mínimo privilegio
Dar a cada parte del sistema solo el acceso que necesita. En OOP: usar private por defecto.
Empieza con private, cambia a protected o public solo si es necesario.
YAGNI — No lo necesitarás
No implementes funcionalidad que "quizás necesites en el futuro". Escribe solo lo que necesitas ahora.
El código que no existe no tiene bugs ni que mantener.
Testing
Escribir pruebas automáticas que verifican que el código funciona correctamente. Detectan regresiones al cambiar código.
PHP: PHPUnit. TDD: escribir el test antes que el código.
buenas_practicas.php
<?php
// ❌ MAL — viola DRY, nombres malos, sin tipos
function f($x, $y) {
    return $x * (1 - $y) * 1.18;
}
$r1 = f(100, 0.1);
$r2 = f(200, 0.1);  // código repetido

// ✅ BIEN — DRY, nombres claros, tipos, SRP
const TASA_IGV = 0.18;

function aplicarDescuento(float $precio, float $descuento): float {
    return $precio * (1 - $descuento);
}

function aplicarIGV(float $precio): float {
    return $precio * (1 + TASA_IGV);
}

function calcularTotal(float $precio, float $descuento = 0): float {
    // Reutiliza las funciones anteriores — no repite lógica
    return aplicarIGV(aplicarDescuento($precio, $descuento));
}

$total1 = calcularTotal(100, 0.10);  // S/ 106.20
$total2 = calcularTotal(200, 0.10);  // S/ 212.40
?>

<?php
// $_SERVER — información de la petición actual
echo $_SERVER['REQUEST_METHOD'];  // GET o POST
echo $_SERVER['REQUEST_URI'];    // /pagina.php?id=5
echo $_SERVER['REMOTE_ADDR'];   // IP del visitante
echo $_SERVER['HTTP_HOST'];      // mi-sitio.com
echo $_SERVER['DOCUMENT_ROOT']; // C:/xampp/htdocs

// $GLOBALS — acceder a variables globales por nombre
$nombre = "PHP";
echo $GLOBALS['nombre'];  // PHP

// $_REQUEST — combina GET + POST + COOKIE
// Útil cuando no sabes si viene por GET o POST
$id = $_REQUEST['id'] ?? null;  // siempre usar ?? para evitar undefined
?>
