Expresiones Regulares en PHP
Sintaxis · metacaracteres · funciones preg_* · grupos de captura · validaciones comunes.
ℹ️ En PHP las regex van entre delimitadores. El más común es /patron/flags. Los flags más usados: i (case-insensitive), m (multilinea), u (UTF-8), s (el . incluye saltos de línea).
regex_sintaxis.php
<?php
// Estructura: /patrón/flags
// ^  → inicio de string
// $  → fin de string
// .  → cualquier carácter (excepto salto de línea)
// *  → 0 o más veces el carácter anterior
// +  → 1 o más veces
// ?  → 0 o 1 vez (opcional)
// {n}   → exactamente n veces
// {n,m} → entre n y m veces
// [abc] → un carácter del conjunto
// [^abc]→ cualquier carácter EXCEPTO los del conjunto
// (abc) → grupo de captura
// a|b   → a O b

// Ejemplos de patrones
preg_match('/^hola/', "hola mundo");      // ✅ empieza con "hola"
preg_match('/mundo$/', "hola mundo");      // ✅ termina con "mundo"
preg_match('/^\d+$/', "12345");           // ✅ solo dígitos
preg_match('/^[A-Z]/i', "Ana");           // ✅ empieza con letra (case insensitive)
preg_match('/\d{4}-\d{2}-\d{2}/', "2024-01-15"); // ✅ formato fecha YYYY-MM-DD
preg_match('/PHP|Python|JS/', "Aprendo PHP");   // ✅ contiene uno de los tres
?>

preg_funciones.php
<?php
$texto = "Visita https://php.net y también https://laravel.com para aprender";

// 1. preg_match — primera coincidencia + grupos
if (preg_match('/(\d{4})-(\d{2})-(\d{2})/', "Hoy es 2024-03-15", $m)) {
    echo "Año: $m[1], Mes: $m[2], Día: $m[3]";
    // $m[0] = "2024-03-15" (match completo)
    // $m[1] = "2024", $m[2] = "03", $m[3] = "15"
}

// Grupos nombrados (?P<nombre>...)
preg_match('/(?P<anio>\d{4})-(?P<mes>\d{2})-(?P<dia>\d{2})/',
    "2024-03-15", $m);
echo $m['anio'];  // 2024 — acceso por nombre

// 2. preg_match_all — todas las coincidencias
preg_match_all('/https?:\/\/[\w.\-]+/', $texto, $urls);
print_r($urls[0]);
// ['https://php.net', 'https://laravel.com']

// 3. preg_replace — reemplazar
$sinHtml    = preg_replace('/<[^>]+>/', '', '<b>Hola</b> <i>Mundo</i>');
echo $sinHtml;  // "Hola Mundo"

// Referencia a grupos en el reemplazo ($1, $2...)
$fechaES = preg_replace('/(\d{4})-(\d{2})-(\d{2})/', '$3/$2/$1', "2024-03-15");
echo $fechaES;  // "15/03/2024"

// preg_replace_callback — reemplazo con función
$resultado = preg_replace_callback('/\b\w+\b/',
    fn($m) => strtoupper($m[0]),
    "hola mundo php"
);
echo $resultado;  // "HOLA MUNDO PHP"

// 4. preg_split — dividir por patrón
$partes = preg_split('/[\s,;]+/', "uno, dos;tres  cuatro");
print_r($partes);  // ['uno', 'dos', 'tres', 'cuatro']
?>
▶ Salida
Año: 2024, Mes: 03, Día: 15
URLs: [https://php.net, https://laravel.com]
15/03/2024 ← fecha reformateada con grupos
HOLA MUNDO PHP ← preg_replace_callback

validar_con_regex.php
<?php
function validar(string $valor, string $patron, string $campo): void {
    $ok = preg_match($patron, $valor) === 1;
    echo ($ok ? "✅" : "❌") . " $campo: '$valor'<br>";
}

validar("ana@mail.com",   '/^[\w.+-]+@[\w-]+\.[a-z]{2,}$/i', "Email");
validar("invalido@",     '/^[\w.+-]+@[\w-]+\.[a-z]{2,}$/i', "Email");
validar("987654321",     '/^9\d{8}$/',                      "Teléfono PE");
validar("20123456789",   '/^(10|20)\d{9}$/',                 "RUC");
validar("Segura123",     '/^(?=.*[A-Z])(?=.*[a-z])(?=.*\d).{8,}$/', "Contraseña");
validar("2024-03-15",   '/^\d{4}-(0[1-9]|1[0-2])-(0[1-9]|[12]\d|3[01])$/', "Fecha");
?>
