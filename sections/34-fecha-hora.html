Fecha y Hora en PHP

Trabaja con fechas usando funciones nativas, la clase DateTime, DateTimeImmutable y Carbon para operaciones legibles y seguras.

Funciones basicas de fecha y hora

fecha_actual.php
<?php
// Obtener timestamp actual (segundos desde 1970-01-01)
$timestamp = time();
echo "Timestamp: " . $timestamp;

// Formatear fecha actual
echo date('d/m/Y H:i:s');           // 26/07/2026 14:30:45
echo date('l, d \d\e F \d\e Y');  // domingo, 26 de julio de 2026
echo date('Y-m-d\TH:i:sP');     // 2026-07-26T14:30:45+02:00 (ISO 8601)

// Diferencia entre dos fechas en dias
$inicio = strtotime('2026-01-01');
$hoy    = strtotime(date('Y-m-d'));
$dias   = ($hoy - $inicio) / (60 * 60 * 24);
echo "Han pasado $dias dias en 2026";
?>
▶ Salida
Timestamp: 1753478445
26/07/2026 14:30:45
mktime_ejemplo.php
<?php
// mktime(hora, min, seg, mes, dia, anio) — crea un timestamp
$navidad = mktime(0, 0, 0, 12, 25, 2026);
echo "Navidad: " . date('Y-m-d', $navidad);

// Crear fecha futura: 90 dias desde hoy
$hoy = time();
$en90 = mktime(
    date('H'), date('i'), date('s'),
    date('m'), date('d') + 90, date('Y')
);
echo "En 90 dias sera: " . date('l d/m/Y', $en90);

// Ultimo dia del mes actual
$ultimo = mktime(0, 0, 0, date('m') + 1, 0, date('Y'));
echo "Ultimo dia: " . date('d/m/Y', $ultimo);
?>
▶ Salida
Navidad: 2026-12-25
En 90 dias sera: sabado 24/10/2026
strtotime_ejemplo.php
<?php
// strtotime() convierte strings en timestamps
echo date('Y-m-d', strtotime('now'));
echo date('Y-m-d', strtotime('+3 days'));
echo date('Y-m-d', strtotime('last monday'));
echo date('Y-m-d', strtotime('+1 month'));
echo date('Y-m-d', strtotime('first day of next month'));

// Calcular dias entre dos fechas de texto
$ini = strtotime('2026-03-15');
$fin = strtotime('2026-12-25');
$dias = ($fin - $ini) / 86400;  // 86400 = 60*60*24
echo "Faltan $dias dias para Navidad";
?>
▶ Salida
2026-07-26
Faltan 285 dias para Navidad
Las funciones basicas usan timestamps (enteros). Para manipulacion compleja de fechas, prefiere DateTime que es mas legible y potente.
2
Clase DateTime
Objetos para representar y manipular fechas de forma orientada a objetos con metodos chainable.
datetime_crear.php
<?php
// Crear desde la fecha actual
$ahora = new DateTime();
echo $ahora->format('d/m/Y H:i:s');

// Crear desde un string
$cumple = new DateTime('2000-06-15 08:30:00');
echo $cumple->format('l d \d\e F \d\e Y');

// Crear con zona horaria
$tokyo = new DateTime('now', new DateTimeZone('Asia/Tokyo'));
echo $tokyo->format('Y-m-d H:i:s e');

// Comparar fechas con diff()
$nacimiento = new DateTime('1990-03-10');
$hoy = new DateTime();
$diff = $nacimiento->diff($hoy);
echo "Edad: {$diff->y} anios, {$diff->m} meses, {$diff->d} dias";
?>
datetime_modify.php
<?php
// modify() — muta el objeto DateTime original
$fecha = new DateTime('2026-07-26');

$fecha->modify('+7 days');
echo $fecha->format('d/m/Y');  // 02/08/2026

$fecha->modify('+3 months');
echo $fecha->format('d/m/Y');  // 02/11/2026

// diff() — calcula la diferencia entre dos fechas
$ini = new DateTime('2026-01-01');
$fin = new DateTime('2026-12-31');
$diff = $ini->diff($fin);

echo $diff->format('%a dias');          // 364 dias
echo $diff->format('%m meses y %d dias'); // 11 meses y 30 dias

// Dias laborales entre dos fechas (saltando fines de semana)
$laborables = 0;
$actual = new DateTime('2026-07-01');
$finMes = new DateTime('2026-07-31');
while ($actual <= $finMes) {
    if ($actual->format('N') < 6) $laborables++;
    $actual->modify('+1 day');
}
echo "Dias laborables en julio: $laborables";  // 23
?>
dateinterval.php
<?php
// DateInterval — representar duraciones con formato ISO 8601
// P = periodo, T = tiempo, D = dias, M = meses, Y = anios, H/I/S = horas/min/seg

$unDia    = new DateInterval('P1D');    // 1 dia
$unMes    = new DateInterval('P1M');    // 1 mes
$unAnio   = new DateInterval('P1Y');    // 1 anio
$unaHora  = new DateInterval('PT1H');   // 1 hora
$complejo = new DateInterval('P1Y2M10DT3H30M'); // 1 anio, 2 meses, 10 dias, 3h 30min

// add() y sub() — sumar/restar intervalos
$fecha = new DateTime('2026-07-26');
$fecha->add($unDia);
echo $fecha->format('d/m/Y');  // 27/07/2026

$fecha->sub(new DateInterval('P15D'));
echo $fecha->format('d/m/Y');  // 12/07/2026

// Fecha limite para un proyecto
$inicio = new DateTime('2026-07-01');
$plazo = $inicio->add(new DateInterval('P3M'));
echo "Fecha limite: {$plazo->format('d/m/Y')}";  // 01/10/2026
?>
dateperiod.php
<?php
// DatePeriod — iterar sobre un rango de fechas
$inicio = new DateTime('2026-07-01');
$fin    = new DateTime('2026-07-31');
$intervalo = new DateInterval('P7D');  // cada 7 dias

$periodo = new DatePeriod($inicio, $intervalo, $fin);

foreach ($periodo as $fecha) {
    echo $fecha->format('d/m/Y (l)') . "\n";
}

// Generar todos los meses del anio 2026
$inicioAnio = new DateTime('2026-01-01');
$finAnio    = new DateTime('2026-12-31');

$meses = new DatePeriod(
    $inicioAnio,
    new DateInterval('P1M'),
    $finAnio,
    DatePeriod::INCLUDE_END_DATE
);

foreach ($meses as $m) {
    echo $m->format('F Y') . "\n";
}
?>
Para calcular la edad exacta de una persona usa $nacimiento->diff(new DateTime()) que devuelve un objeto DateInterval con las propiedades y, m y d.
3
DateTimeImmutable
Version inmutable de DateTime: cada operacion devuelve un nuevo objeto sin modificar el original. Mas seguro para estado compartido.
Por que inmutable? Con DateTime, si pasas el objeto a una funcion y esta lo modifica, el original cambia (efecto secundario). DateTimeImmutable evita esto porque cada modificacion crea un nuevo objeto.
immutable_vs_mutable.php
<?php
// ============================================
//  PROBLEMA CON DateTime (mutable)
// ============================================
$fecha = new DateTime('2026-07-26');
$original = $fecha;  // apunta al mismo objeto

$fecha->modify('+7 days');
echo "Original: " . $original->format('d/m/Y') . "\n";
echo "Fecha:    " . $fecha->format('d/m/Y') . "\n";
// Ambos muestran 02/08/2026 — el original se cambio

// ============================================
//  SOLUCION CON DateTimeImmutable
// ============================================
$fecha = new DateTimeImmutable('2026-07-26');
$original = $fecha;

$nueva = $fecha->modify('+7 days');  // retorna NUEVO objeto
echo "Original: " . $original->format('d/m/Y') . "\n";
echo "Nueva:    " . $nueva->format('d/m/Y') . "\n";
// Original: 26/07/2026 — intocado
// Nueva:    02/08/2026 — nuevo objeto

// ============================================
//  RESULTADO SEGUNDO A SEGUNDO
// ============================================
$origA = new DateTime('2026-07-26');
$origB = new DateTimeImmutable('2026-07-26');

// Mutable: ambas variables apuntan al MISMO objeto
$copia1 = $origA;
$copia1->modify('+1 year');
echo var_export($origA === $copia1, true);  // true (mismo objeto)

// Immutable: son objetos DISTINTOS
$copia2 = $origB->modify('+1 year');
echo var_export($origB === $copia2, true);  // false (distintos)
?>
▶ Salida
Original: 26/07/2026
Nueva: 02/08/2026
Usa DateTimeImmutable por defecto en tu codigo. Solo cambia a DateTime si necesitas mutar el objeto en multiples pasos encadenados dentro de una unica variable.

Carbon (intro)
Wrapper de DateTime con API legible en ingles/espanol: addDays(), diffForHumans(), isPast() y mas.
  1. Instala Carbon con Composer: composer require nesbot/carbon
  2. En tu archivo incluye el autoloader: require 'vendor/autoload.php';
  3. Usa las clases Carbon\Carbon o Carbon\CarbonImmutable.
carbon_basico.php
<?php
require_once 'vendor/autoload.php';
use Carbon\Carbon;

// Fechas directas sin new
echo Carbon::now()->format('Y-m-d H:i:s');
echo Carbon::tomorrow()->format('Y-m-d');
echo Carbon::yesterday()->format('Y-m-d');

// Metodos legibles para modificar fechas
$hoy = Carbon::now();
echo $hoy->addDays(7)->format('d/m/Y');
echo $hoy->subMonths(3)->format('d/m/Y');
echo $hoy->addYears(2)->format('d/m/Y');

// Validaciones directas
echo $hoy->isWeekend() ? 'Fin de semana' : 'Dia laboral';
echo $hoy->isPast() ? 'Pasado' : 'Futuro';
echo Carbon::create(2026, 12, 25)->isFuture() ? 'Si' : 'No';

// Diferencia exacta entre fechas
$inicio = Carbon::create(2026, 1, 1);
$fin    = Carbon::now();
echo $inicio->diffInDays($fin) . " dias transcurridos";
?>
carbon_human.php
<?php
require_once 'vendor/autoload.php';
use Carbon\Carbon;

// diffForHumans() — diferencias legibles automaticamente
$pasado = Carbon::now()->subDays(3);
$futuro = Carbon::now()->addHours(5);
$lejano = Carbon::now()->subMonths(6);

echo $pasado->diffForHumans();   // 3 days ago
echo $futuro->diffForHumans();   // 5 hours from now
echo $lejano->diffForHumans();  // 6 months ago

// En espanol con locale (requiere ext-intl)
Carbon::setLocale('es');
echo $pasado->diffForHumans();   // hace 3 dias
echo $futuro->diffForHumans();   // dentro de 5 horas
echo $lejano->diffForHumans();  // hace 6 meses

// Para blogs, foros, redes sociales — ideal
$post = Carbon::parse('2026-07-20 09:15:00');
echo "Publicado " . $post->diffForHumans();  // Publicado 6 days ago
?>
carbon_deadlines.php
<?php
require_once 'vendor/autoload.php';
use Carbon\Carbon;

// Calcular fecha limite de una tarea
$tarea = [
    'nombre'  => 'Entregar informe',
    'creada'  => Carbon::parse('2026-07-15'),
    'plazo'   => 10,  // dias
];

$deadline = $tarea['creada']->addDays($tarea['plazo']);
$hoy     = Carbon::now();

echo "Deadline: " . $deadline->format('d/m/Y') . "\n";
echo "Estado: " . $deadline->isPast() ? "Vencida" : "Activa";
echo "\n" . $deadline->diffForHumans();

// Resumen de multiples fechas
$tareas = [
    Carbon::parse('2026-07-20')->addDays(5),
    Carbon::parse('2026-07-22')->addDays(3),
    Carbon::parse('2026-07-10')->addDays(10),
];

echo "\nProximas entregas:\n";
foreach ($tareas as $t) {
    $estado = $t->isPast() ? "VENCIDA" : $t->diffForHumans();
    echo " - {$t->format('d/m')}: $estado\n";
}
?>
▶ Salida
Deadline: 25/07/2026
Estado: Vencida
Carbon es el estandar de facto en Laravel. Si trabajas con Symfony o proyectos plain PHP, DateTimeImmutable es suficiente para la mayoria de casos.
