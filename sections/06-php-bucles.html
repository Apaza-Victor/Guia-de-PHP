Bucles
for / while / do-while / foreach · break · continue · destructuring en bucles.
¿Qué bucle usar en cada situación?
for
Cuando sabes cuántas veces se va a repetir antes de empezar.
Contar del 1 al 100
Recorrer array por índice
Tabla de multiplicar
Paginar resultados
while
Cuando no sabes cuántas veces se repetirá. Puede que no se ejecute nunca.
Leer filas de base de datos
Procesar hasta fin de archivo
Esperar condición externa
Juego: jugar mientras haya vidas
do-while
Cuando el bloque debe ejecutarse al menos una vez sí o sí.
Mostrar menú y esperar opción
Pedir contraseña hasta acertar
Validar entrada de usuario
Primer intento siempre necesario
foreach
Cuando tienes un array u objeto iterable y quieres recorrer cada elemento.
Listar productos del carrito
Mostrar usuarios de BD
Procesar formulario con campos
Cualquier colección de datos
Bucle ¿Cuándo usarlo? ¿Ejecuta 0 veces? Ideal para Evitar si…
for Conoces el número exacto de iteraciones Sí (si condición es false desde el inicio) Índices, contadores, rangos numéricos Iterar arrays asociativos o colecciones
while Condición dinámica, número desconocido Sí (si condición ya es false) Lectura de archivos, BD, esperar eventos Sabes cuántas veces vas a repetir
do-while Necesitas al menos una ejecución garantizada No — siempre ejecuta al menos 1 vez Menús, validar entrada, primer intento El bloque podría no tener que ejecutarse
foreach Tienes un array o iterable y recorres cada elemento Sí (si el array está vacío) Arrays indexados y asociativos, objetos Necesitas controlar el índice manualmente
Árbol de decisión — ¿qué bucle elijo?
¿Tienes un array o colección?
├─ Sí → foreach
└─ No → ¿Sabes cuántas veces se repite?
    ├─ Sí → for
    └─ No → ¿Debe ejecutarse al menos una vez?
        ├─ Sí → do-while (menú, validación)
        └─ No → while (condición externa)
caso_for.php — sabes cuántas veces
<?php
// Mostrar los 5 primeros números
// → Sabemos exactamente que son 5
for ($i = 1; $i <= 5; $i++) {
    echo $i . " ";
}
// Salida: 1 2 3 4 5
?>
caso_foreach.php — tienes array
<?php
// Listar frutas del array
// → Tienes colección, usa foreach
$frutas = ["Manzana", "Pera", "Uva"];
foreach ($frutas as $fruta) {
    echo $fruta . "<br>";
}
?>
caso_while.php — condición externa
<?php
// Leer BD: no sabemos cuántas filas hay
// → Cantidad desconocida → while
$stmt = $pdo->query("SELECT nombre FROM usuarios");
while ($fila = $stmt->fetch()) {
    echo $fila["nombre"] . "<br>";
}
?>
caso_dowhile.php — al menos 1 vez
<?php
// Menú: siempre se muestra al menos una vez
// → Al menos 1 ejecución → do-while
do {
    echo "1. Ver productos\n2. Salir\n";
    $opcion = readline("Elige: ");
} while ($opcion !== "2");
echo "¡Hasta luego!";
?>
Diagrama de flujo: for
for.php
<?php
// for clásico: init ; condición ; incremento
for ($i = 1; $i <= 5; $i++) {
    echo "Vuelta $i ";
}
// Vuelta 1 Vuelta 2 Vuelta 3 Vuelta 4 Vuelta 5

// for hacia atrás
for ($i = 5; $i >= 1; $i--) {
    echo $i . " ";
}
// 5 4 3 2 1

// for con saltos de 2 en 2
for ($i = 0; $i <= 10; $i += 2) {
    echo $i . " ";
}
// 0 2 4 6 8 10

// for recorriendo un array por índice
$frutas = ["Manzana", "Pera", "Uva"];
for ($i = 0; $i < count($frutas); $i++) {
    echo "[$i] {$frutas[$i]}<br>";
}

// Bucles anidados — tabla de multiplicar
for ($i = 1; $i <= 3; $i++) {
    for ($j = 1; $j <= 3; $j++) {
        echo "$ix$j=" . ($i*$j) . " ";
    }
    echo "<br>";
}
?>
▶ Salida
Vuelta 1 Vuelta 2 Vuelta 3 Vuelta 4 Vuelta 5
5 4 3 2 1
0 2 4 6 8 10
1x1=1 1x2=2 1x3=3
2x1=2 2x2=4 2x3=6
3x1=3 3x2=6 3x3=9
while — condición ANTES
do-while — condición DESPUÉS
while_dowhile.php
<?php
// while — evalúa la condición ANTES de entrar
$contador = 1;
while ($contador <= 5) {
    echo "Valor: $contador<br>";
    $contador++;
}

// while leyendo resultados de base de datos (patrón común)
// $stmt = $pdo->query("SELECT * FROM usuarios");
// while ($fila = $stmt->fetch()) {
//     echo $fila['nombre'] . "<br>";
// }

// do-while — ejecuta el bloque AL MENOS UNA VEZ
// (evalúa la condición DESPUÉS de la primera ejecución)
$intentos = 0;
do {
    echo "Intento $intentos<br>";
    $intentos++;
} while ($intentos < 3);
// Imprime: Intento 0, Intento 1, Intento 2

// Diferencia clave: si la condición es false desde el principio
$n = 10;

while ($n < 5) { echo "while"; }  // No imprime nada
do { echo "do-while"; } while($n < 5); // Imprime "do-while" UNA vez
?>
▶ Salida
Valor: 1 | Valor: 2 | Valor: 3 | Valor: 4 | Valor: 5
Intento 0 | Intento 1 | Intento 2

Diagrama de flujo: foreach
foreach_avanzado.php
<?php
// foreach básico — array indexado
$colores = ["rojo", "verde", "azul"];
foreach ($colores as $color) {
    echo $color . " ";  // rojo verde azul
}

// foreach con clave => valor
$precios = ["Laptop" => 999, "Mouse" => 25, "Teclado" => 75];
foreach ($precios as $producto => $precio) {
    echo "$producto: S/ $precio<br>";
}

// Modificar elementos por referencia con &
$numeros = [1, 2, 3, 4];
foreach ($numeros as &$num) {   // & para modificar original
    $num *= 2;
}
unset($num);  // importante: romper la referencia al terminar
print_r($numeros);  // [2, 4, 6, 8]

// Destructuring en foreach (list() / []) — arrays multidimensionales
$personas = [
    ["Ana", 28, "Lima"],
    ["Luis", 35, "Bogotá"],
];
foreach ($personas as [$nombre, $edad, $ciudad]) {
    echo "$nombre ($edad) vive en $ciudad<br>";
}

// Destructuring de arrays asociativos
$usuarios = [
    ["nombre" => "María", "rol" => "admin"],
    ["nombre" => "Pedro", "rol" => "editor"],
];
foreach ($usuarios as ["nombre" => $nombre, "rol" => $rol]) {
    echo "$nombre es $rol<br>";
}
?>
▶ Salida
rojo verde azul
Laptop: S/ 999 | Mouse: S/ 25 | Teclado: S/ 75
Array: [2, 4, 6, 8]
Ana (28) vive en Lima
Luis (35) vive en Bogotá
break — detiene el bucle
continue — salta iteración
break_continue.php
<?php
// break — detiene el bucle completamente
for ($i = 1; $i <= 10; $i++) {
    if ($i === 5) break;   // sale cuando i llega a 5
    echo $i . " ";
}
// Salida: 1 2 3 4

// continue — salta a la siguiente iteración
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) continue;  // salta los pares
    echo $i . " ";
}
// Salida: 1 3 5 7 9 (solo impares)

// break con nivel numérico — rompe N niveles de bucle
for ($i = 0; $i < 3; $i++) {
    for ($j = 0; $j < 3; $j++) {
        if ($i === 1 && $j === 1) break 2;  // rompe los 2 bucles
        echo "($i,$j) ";
    }
}
// Salida: (0,0) (0,1) (0,2) (1,0)

// Caso práctico: buscar en un array y salir al encontrar
$productos = ["Laptop", "Mouse", "Teclado", "Monitor"];
$buscar = "Teclado";
foreach ($productos as $i => $p) {
    if ($p === $buscar) {
        echo "✅ Encontrado en índice $i";
        break;  // no seguir buscando
    }
}
?>
▶ Salida
1 2 3 4
1 3 5 7 9
(0,0) (0,1) (0,2) (1,0)
Encontrado en índice 2
