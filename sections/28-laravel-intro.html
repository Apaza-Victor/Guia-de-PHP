Introduccion a Laravel

Descubre el framework MVC mas popular de PHP: routing, Blade, Eloquent ORM, migraciones y Artisan CLI.

1
Que es Laravel
Framework MVC basado en Symfony. Proporciona routing, ORM, templates y herramientas de CLI listas para usar.
Comparativa de enfoques
# PHP crudo — todo manual
<?php
if ($_SERVER['REQUEST_URI'] == '/usuarios') {
    $pdo = new PDO('mysql:host=localhost;db=app', 'root', '');
    $stmt = $pdo->query('SELECT * FROM usuarios');
    // renderizar HTML manualmente...
}
?>

# Laravel — conciso y expresivo
<?php
Route::get('/usuarios', function () {
    return view('usuarios.index', [
        'usuarios' => Usuario::all()
    ]);
});
?>

2
Instalacion
Crea un proyecto Laravel completo con Composer en un solo comando.
  1. Instala Composer desde getcomposer.org si aun no lo tienes.
  2. Crea el proyecto: composer create-project laravel/laravel mi-app
  3. Entra a la carpeta: cd mi-app
  4. Inicia el servidor de desarrollo: php artisan serve
  5. Abre http://localhost:8000 en tu navegador.
Terminal
# Crear proyecto Laravel
composer create-project laravel/laravel mi-app

# Iniciar servidor de desarrollo
cd mi-app
php artisan serve

# Salida: Laravel development server started: http://127.0.0.1:8000

Routing
Define rutas HTTP en routes/web.php con una sintaxis fluida y legible.
routes/web.php
<?php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\HomeController;
use App\Http\Controllers\UserController;

// Rutas por metodo HTTP
Route::get('/', [HomeController::class, 'index']);
Route::post('/usuarios', [UserController::class, 'store']);
Route::put('/usuarios/{id}', [UserController::class, 'update']);
Route::delete('/usuarios/{id}', [UserController::class, 'destroy']);

// Closure rapida
Route::get('/about', function () {
    return view('about');
});

// Ruta con nombre (facil de referenciar)
Route::get('/dashboard', [HomeController::class, 'dashboard'])
    ->name('dashboard');

// Usar nombre: route('dashboard') en Blade o PHP
?>
routes/web.php
<?php
use Illuminate\Support\Facades\Route;
use App\Http\Controllers\PostController;

// Parametro obligatorio
Route::get('/posts/{id}', [PostController::class, 'show']);

// Parametro opcional con default
Route::get('/buscar/{termino?}', function ($termino = 'todos') {
    return "Buscando: {$termino}";
});

// Parametro con restriccion
Route::get('/user/{id}', [UserController::class, 'show'])
    ->where('id', '[0-9]+');

// Multiples rutas CRUD con resource
Route::resource('/articulos', ArticuloController::class);
// Genera: index, create, store, show, edit, update, destroy

?>
routes/web.php
<?php
use Illuminate\Support\Facades\Route;

Route::name('api.')->prefix('api')->group(function () {

        ->name('usuarios'); // -> api.usuarios
});

?>

Blade Templates
Motor de plantillas con herencia, componentes y sintaxis limpia. No compila — compila en PHP optimizado.
resources/views/layouts/app.blade.php
<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <title>@yield('title', 'Mi App')</title>
</head>
<body>
    <nav>
        <a href="{{ route('dashboard') }}">Dashboard</a>

    <!-- Contenido principal que cada pagina inyecta -->

        @yield('content')
    </main>

    <!-- Seccion de scripts -->
    @yield('scripts')

</html>

Eloquent ORM
ORM activo por defecto en Laravel. Cada tabla se modela como una clase con metodos expresivos.
app/Models/User.php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class User extends Model {
    use HasFactory;

    protected $table = 'users';
    protected $fillable = ['name', 'email', 'password'];
    protected $hidden = ['password', 'remember_token'];
    protected $casts = ['email_verified_at' => 'datetime'];
}
?>
app/Models/Post.php
<?php
namespace App\Models;

use Illuminate\Database\Eloquent\Model;
use Illuminate\Database\Eloquent\Factories\HasFactory;

class Post extends Model {
    use HasFactory;

    protected $fillable = ['title', 'body', 'user_id'];

    // Un post pertenece a un usuario
    public function user() {
        return $this->belongsTo(User::class);
    }

    // Un post tiene muchos comentarios
    public function comments() {
        return $this->hasMany(Comment::class);
    }
}
?>

Relaciones Eloquent
<?php
use App\Models\{User, Post, Comment, Profile};

// hasOne — Un usuario tiene un perfil
class User extends Model {
    public function profile() {
        return $this->hasOne(Profile::class);
    }
}

// hasMany — Un usuario tiene muchos posts
public function posts() {
    return $this->hasMany(Post::class);
}

// belongsTo — Un post pertenece a un usuario
public function user() {
    return $this->belongsTo(User::class);
}

// Uso en controlador
$user = User::with(['posts', 'profile'])->find(1);
echo $user->profile->bio;
echo $user->posts->count();

Migraciones y Seeders
Controla la estructura de tu BD con migraciones versionadas y carga datos de prueba con seeders.
Terminal
# Crear migracion para tabla users
php artisan make:migration create_users_table

# Crear migracion con modelo
php artisan make:model Post -m

# Ejecutar migraciones
php artisan migrate

# Rollback (deshacer ultima migracion)
php artisan migrate:rollback
database/migrations/2024_01_15_create_users_table.php
<?php
use Illuminate\Database\Migrations\Migration;
use Illuminate\Database\Schema\Blueprint;
use Illuminate\Support\Facades\Schema;

return new class extends Migration {
    public function up(): void {

            $table->string('name');
            $table->string('email')->unique();
            $table->timestamp('email_verified_at')->nullable();
            $table->string('password');
            $table->rememberToken();
            $table->timestamps();
        });
    }

    public function down(): void {
        Schema::dropIfExists('users');
    }

?>
database/seeders/DatabaseSeeder.php
<?php
namespace Database\Seeders;

use Illuminate\Database\Seeder;
use App\Models\User;

class DatabaseSeeder extends Seeder {
    public function run(): void {
        // Crear usuario admin manual
        User::create([
            'name'     => 'Admin',
            'email'    => 'admin@mail.com',
            'password' => bcrypt('password')
        ]);

        // Crear 50 usuarios con factory

?>
Terminal
# Ejecutar seeders
php artisan db:seed

# Ejecutar seeder especifico
php artisan db:seed --class=UserSeeder

# Fresh: borrar BD + migrar + sembrar
php artisan migrate:fresh --seed

Artisan CLI
Herramienta de linea de comandos integrada. Genera codigo, gestiona BD y ejecuta tareas del framework.
ComandoQue hace
php artisan serveInicia servidor de desarrollo local
php artisan make:controller NameCrea un controlador en app/Http/Controllers
php artisan make:model NameCrea un modelo en app/Models
php artisan make:model Name -mcrCrea modelo + migracion + controller + resource
php artisan make:migration nameCrea archivo de migracion en database/migrations
php artisan make:seeder NameCrea un seeder en database/seeders
php artisan make:factory NameCrea un factory para generar datos falsos
php artisan make:middleware NameCrea un middleware en app/Http/Middleware
php artisan migrateEjecuta todas las migraciones pendientes
php artisan migrate:rollbackDeshace la ultima migracion ejecutada
php artisan migrate:freshBorra BD, re-migra y sembrar
php artisan db:seedEjecuta los seeders del proyecto
php artisan route:listMuestra todas las rutas registradas
php artisan tinkerConsola interactiva para probar codigo
El atajo make:model Post -mcr crea el modelo, la migracion y el controller con resource routes en un solo comando. Muy util para empezar rapidamente un recurso CRUD.
