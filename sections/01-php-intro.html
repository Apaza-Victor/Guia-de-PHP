¿Qué es PHP?
Lenguaje de scripting del lado del servidor para crear páginas web dinámicas.

PHP (Hypertext Preprocessor) es un lenguaje interpretado que se ejecuta en el servidor. El cliente solo recibe HTML, CSS y JS como resultado. Es el lenguaje detrás de WordPress, Laravel, Facebook (inicialmente) y millones de sitios web.

mi_primer_script.php 
<!-- El código PHP va dentro de las etiquetas ?> -->
<?php
  // Esto es un comentario de una línea
  /* Esto es un comentario
     de múltiples líneas */

  echo "¡Hola, Mundo!";
  echo "<br>";
  echo "PHP versión: " . phpversion();
?>
