APIs y JSON

Consume APIs externas con cURL, trabaja con JSON y crea tu propia API REST en PHP.

1
JSON — encode y decode
JSON es el formato estándar para intercambiar datos entre aplicaciones.
json.php
<?php
// Array PHP → JSON string
$datos = [
    'nombre' => 'Ana García',
    'edad'   => 28,
    'activo' => true,
    'roles'  => ['admin', 'editor']
];

$json = json_encode($datos, JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE);
echo $json;

// JSON string → Array PHP
$cadena = '{"producto":"Laptop","precio":999.99}';
$array  = json_decode($cadena, true);  // true → array asociativo
echo $array['producto'];                // Laptop

// JSON string → Objeto PHP (sin el parámetro true)
$obj = json_decode($cadena);
echo $obj->precio;  // 999.99

// Verificar errores JSON
if (json_last_error() !== JSON_ERROR_NONE) {
    echo "❌ JSON inválido: " . json_last_error_msg();
}
?>
▶ Salida
{ "nombre": "Ana García", "edad": 28, "activo": true, "roles": ["admin","editor"] }
Laptop  |  999.99
2
Consumir APIs con cURL
cURL permite hacer peticiones HTTP (GET, POST, PUT, DELETE) desde PHP.
curl_get.php
<?php
// Función reutilizable para peticiones GET
function apiGet(string $url, array $headers = []): array {
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL            => $url,
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER     => array_merge(['Accept: application/json'], $headers),
        CURLOPT_TIMEOUT        => 10,
        CURLOPT_FOLLOWLOCATION => true,
    ]);
    $respuesta  = curl_exec($ch);
    $httpCode   = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    return ['status' => $httpCode, 'data' => json_decode($respuesta, true)];
}

// Consumir API pública (JSONPlaceholder)
$resultado = apiGet('https://jsonplaceholder.typicode.com/users/1');

if ($resultado['status'] === 200) {
    $usuario = $resultado['data'];
    echo "Nombre: {$usuario['name']}\n";
    echo "Email: {$usuario['email']}\n";
} else {
    echo "❌ Error HTTP: {$resultado['status']}";
}
?>
▶ Salida
Nombre: Leanne Graham
Email: Sincere@april.biz
curl_post.php
<?php
function apiPost(string $url, array $datos, array $headers = []): array {
    $ch = curl_init();
    curl_setopt_array($ch, [
        CURLOPT_URL            => $url,
        CURLOPT_POST           => true,
        CURLOPT_POSTFIELDS     => json_encode($datos),
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_HTTPHEADER     => array_merge([
            'Content-Type: application/json',
            'Accept: application/json',
        ], $headers),
    ]);
    $respuesta = curl_exec($ch);
    $httpCode  = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);
    return ['status' => $httpCode, 'data' => json_decode($respuesta, true)];
}

$resultado = apiPost('https://jsonplaceholder.typicode.com/posts', [
    'title'  => 'Mi primer post',
    'body'   => 'Contenido del post',
    'userId' => 1,
]);

echo "Creado con ID: {$resultado['data']['id']}";  // 101
?>
▶ Salida
Creado con ID: 101
curl_auth.php
<?php
// API con Bearer Token (JWT)
$token = 'eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...';

$resultado = apiGet('https://api.ejemplo.com/mis-datos', [
    "Authorization: Bearer $token",
]);

// API con Basic Auth
$ch = curl_init();
curl_setopt_array($ch, [
    CURLOPT_URL            => 'https://api.ejemplo.com/datos',
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_USERPWD        => 'usuario:contraseña',   // Basic Auth
    CURLOPT_SSL_VERIFYPEER => true,  // SIEMPRE verificar SSL en producción
]);
$resp = curl_exec($ch);
curl_close($ch);
?>
⚠️ Nunca escribas tokens o contraseñas directamente en el código. Usa variables de entorno o un archivo .env que no se suba a Git.
3
Crear tu propia API REST
Responde con JSON, maneja métodos HTTP y cabeceras CORS desde PHP.
api.php
<?php
// Cabeceras — indicar que devuelves JSON y permitir CORS
header('Content-Type: application/json; charset=UTF-8');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE');
header('Access-Control-Allow-Headers: Content-Type, Authorization');

// Función helper para responder
function responder(array $datos, int $codigo = 200): void {
    http_response_code($codigo);
    echo json_encode($datos, JSON_UNESCAPED_UNICODE);
    exit;
}

// Leer el método HTTP y la ruta
$metodo = $_SERVER['REQUEST_METHOD'];
$ruta   = trim($_SERVER['PATH_INFO'] ?? '/', '/');
$cuerpo = json_decode(file_get_contents('php://input'), true) ?? [];

// Enrutador simple
match("$metodo /$ruta") {
    'GET /productos'   => responder(['data' => obtenerProductos()]),
    'POST /productos'  => responder(['data' => crearProducto($cuerpo)], 201),
    default            => responder(['error' => 'Ruta no encontrada'], 404),
};

function obtenerProductos(): array {
    // Aquí consultas la BD con PDO
    return [
        ['id' => 1, 'nombre' => 'Laptop', 'precio' => 999.99],
        ['id' => 2, 'nombre' => 'Teclado', 'precio' => 89.00],
    ];
}
?>
▶ GET /api.php/productos devuelve
{"data":[{"id":1,"nombre":"Laptop","precio":999.99},{"id":2,"nombre":"Teclado","precio":89}]}

4
Variables Superglobales de Servidor
$_SERVER y $_ENV: información del servidor, petición HTTP y variables de entorno.
superglobales.php
<?php
// $_SERVER — info del servidor y la petición
echo $_SERVER['REQUEST_METHOD'];    // GET, POST, PUT...
echo $_SERVER['REQUEST_URI'];       // /api/productos?page=1
echo $_SERVER['HTTP_HOST'];          // localhost o mi-dominio.com
echo $_SERVER['REMOTE_ADDR'];        // IP del visitante
echo $_SERVER['HTTP_USER_AGENT'];    // navegador del usuario
echo $_SERVER['DOCUMENT_ROOT'];      // ruta raíz del servidor

// Detectar si es HTTPS
$esHttps = (!empty($_SERVER['HTTPS']) && $_SERVER['HTTPS'] !== 'off');
$protocolo = $esHttps ? 'https' : 'http';

// Leer header personalizado
$tokenBearer = $_SERVER['HTTP_AUTHORIZATION'] ?? '';

// $_ENV — variables de entorno (del sistema o .env)
$dbPassword = getenv('DB_PASSWORD');     // Leer variable de entorno
putenv('MI_VAR=valor');                  // Definir variable de entorno

// URL completa actual
$urlActual = $protocolo . '://' . $_SERVER['HTTP_HOST'] . $_SERVER['REQUEST_URI'];
echo $urlActual;  // https://mi-dominio.com/api/productos
?>
▶ Ejemplo de valores
GET  |  /api/productos?page=1  |  localhost
https://mi-dominio.com/api/productos
