Diagrama Detallado — Request/Response HTTP
El servidor web nunca ejecuta PHP directamente. Lo delega a PHP-FPM (FastCGI Process Manager) que mantiene procesos PHP listos para responder — mucho más eficiente que crear un proceso por cada petición.

Patrón MVC — Model View Controller
La arquitectura más usada en PHP. Separa datos, lógica y presentación.
Diagrama MVC — Flujo completo de datos

MVC correcto

  • → Controller recibe HTTP y delega
  • → Model hace queries, retorna objetos
  • → View solo imprime variables
  • → Cada capa ignora los detalles de las otras

MVC roto (anti-patrón)

  • → SQL directamente en el HTML
  • → Lógica de negocio dentro de la vista
  • → Controller con 500 líneas de código
  • → Model que genera HTML directamente
MVC en PHP — Ejemplo completo
<?php
// === MODEL — src/Models/Producto.php ===
class Producto {
    public function __construct(private PDO $pdo) {}
    public function findAll(): array {
        return $this->pdo->query("SELECT * FROM productos")->fetchAll();
    }
}
// === CONTROLLER — src/Controllers/ProductoController.php ===
class ProductoController {
    public function __construct(private Producto $model) {}
    public function index(): void {
        $productos = $this->model->findAll();
        require 'views/productos/index.php';
    }
}
// === VIEW — views/productos/index.php ===
?>
<ul>
<?php foreach($productos as $p): ?>
  <li><?= htmlspecialchars($p['nombre']) ?> — S/ <?= $p['precio'] ?></li>
<?php endforeach; ?>
</ul>

POO — Diagrama UML de Clases
Herencia, interfaces y relaciones entre clases con ejemplos reales.
UML — Sistema de Usuarios: Herencia + Interfaces
poo_completo.php — Herencia + Interface + Polimorfismo
<?php
interface Autenticable {
    public function login(string $pass): bool;
    public function logout(): void;
}

abstract class Usuario implements Autenticable {
    public function __construct(
        protected int $id,
        protected string $nombre,
        protected string $email
    ) {}
    abstract public function getRol(): string;
    public function logout(): void { session_destroy(); }
}

class Admin extends Usuario {
    public function getRol(): string { return 'admin'; }
    public function ban(Usuario $u): void { /* ... */ }
    public function login(string $pass): bool { return password_verify($pass, ''); }
}
class Cliente extends Usuario {
    public function __construct(int $id, string $nombre, string $email,
        private float $saldo = 0.0
    ) { parent::__construct($id, $nombre, $email); }
    public function getRol(): string { return 'cliente'; }
    public function login(string $pass): bool { return password_verify($pass, ''); }
}

// Polimorfismo — mismo método, resultados distintos
$usuarios = [new Admin(1, "Pedro", "p@x.com"), new Cliente(2, "Ana", "a@x.com")];
foreach($usuarios as $u) echo $u->getRol() . "\n";  // "admin" / "cliente"
?>

Patrones de Diseño en PHP
Singleton, Factory, Repository, Observer — los 4 más usados con diagramas y código.
Singleton — Una sola instancia global
¿Cuándo usarlo? Cuando necesitas exactamente una instancia global — conexión a BD, logger, cache. Evita múltiples conexiones costosas.
singleton.php
<?php
class Database {
    private static ?Database $instance = null;
    private PDO $conn;

    private function __construct() {
        $this->conn = new PDO("mysql:host=localhost", "root", "");
    }
    public static function getInstance(): static {
        if (static::$instance === null)
            static::$instance = new static();
        return static::$instance;
    }
    public function getConn(): PDO { return $this->conn; }
}

$db1 = Database::getInstance();
$db2 = Database::getInstance();
var_dump($db1 === $db2);  // bool(true)
?>
Factory — Fábrica de objetos
¿Cuándo usarlo? Cuando creas objetos sin especificar la clase exacta. Ideal para notificaciones, pagos (Visa/PayPal/Yape) o reportes (PDF/Excel/CSV).
factory.php
<?php
interface Notificacion {
    public function send(string $msg): void;
}
class Email implements Notificacion {
    public function send(string $msg): void
    { mail("user@x.com","Notif",$msg); }
}
class SMS implements Notificacion {
    public function send(string $msg): void
    { /* API SMS */ }
}
class NotifFactory {
    public static function create(string $tipo): Notificacion {
        return match($tipo) {
            'email' => new Email(),
            'sms'   => new SMS(),
            default => throw new InvalidArgumentException("Tipo inválido")
        };
    }
}
// El cliente no sabe qué clase se instancia
NotifFactory::create($_POST['canal'])->send("Pedido listo");
?>

repository_pattern.php
<?php
interface ProductoRepository {
    public function findAll(): array;
    public function findById(int $id): ?Producto;
    public function save(Producto $p): void;
    public function delete(int $id): void;
}
class MysqlProductoRepository implements ProductoRepository {
    public function __construct(private PDO $pdo) {}
    public function findAll(): array {
        return $this->pdo->query("SELECT * FROM productos")->fetchAll();
    }
    public function findById(int $id): ?Producto {
        $s = $this->pdo->prepare("SELECT * FROM productos WHERE id=?");
        $s->execute([$id]);
        $row = $s->fetch();
        return $row ? new Producto($row['id'], $row['nombre'], $row['precio']) : null;
    }
    public function save(Producto $p): void { /* INSERT / UPDATE */ }
    public function delete(int $id): void { /* DELETE */ }
}
// Controller desacoplado de SQL
class ProductoController {
    public function __construct(private ProductoRepository $repo) {}
    public function index() { return $this->repo->findAll(); }
}
?>
Observer — Notificaciones en cadena (Eventos)
observer.php
<?php
interface Observer {
    public function handle(array $data): void;
}
class EventEmitter {
    private array $listeners = [];
    public function on(string $event, Observer $obs): void
    { $this->listeners[$event][] = $obs; }
    public function emit(string $event, array $data): void {
        foreach($this->listeners[$event] ?? [] as $obs)
            $obs->handle($data);
    }
}
class EnviarEmail implements Observer {
    public function handle(array $data): void
    { echo "Email enviado para pedido #{$data['id']}\n"; }
}
class ActualizarStock implements Observer {
    public function handle(array $data): void
    { echo "Stock actualizado\n"; }
}
$emitter = new EventEmitter();
$emitter->on('pedido.nuevo', new EnviarEmail());
$emitter->on('pedido.nuevo', new ActualizarStock());
$emitter->emit('pedido.nuevo', ['id' => 42]);
?>

Flujo de Seguridad — Capas de Defensa
Modelo de defensa en profundidad contra XSS, CSRF e Injection.
Defense in Depth — 4 capas de protección
Inv → 400 ② Sanitizar htmlspecialchars strip_tags Escapar salida → Anti-XSS ③ BD Segura PDO prepare() Bind params Least privilege → Anti-SQLi ④ CSRF + Auth CSRF Token Session segura password_hash → Anti-CSRF Input seguro → BD → Respuesta protegida Cada capa detiene un tipo de ataque. Si una falla, las otras siguen protegiendo. ① Validar → ② Sanitizar → ③ Queries seguras → ④ Autenticación
Nunca confíes en el input del usuario. Valida siempre en el servidor aunque ya valides en el cliente. El cliente puede ser manipulado; el servidor es tu última línea de defensa.

api_rest.php — Router con match()
<?php
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');

$method = $_SERVER['REQUEST_METHOD'];
$uri    = parse_url($_SERVER['REQUEST_URI'], PHP_URL_PATH);
$parts  = explode('/', trim($uri,'/'));  // ['api','productos','42']
$resource = $parts[1] ?? '';
$id       = isset($parts[2]) ? (int)$parts[2] : null;
$body     = json_decode(file_get_contents('php://input'), true);

match(true) {
    $resource==='productos'&&$method==='GET'   &&!$id => listar(),
    $resource==='productos'&&$method==='GET'   && $id => obtener($id),
    $resource==='productos'&&$method==='POST'        => crear($body),
    $resource==='productos'&&$method==='PUT'   && $id => actualizar($id,$body),
    $resource==='productos'&&$method==='DELETE'&& $id => eliminar($id),
    default => (http_response_code(404) &&
                 print json_encode(['error'=>'Ruta no encontrada']))
};

function crear(array $body): void {
    http_response_code(201);
    echo json_encode(['id'=>99, ...$body]);
}
?>
