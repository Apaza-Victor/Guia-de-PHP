Leer y escribir archivos
file_get/put_contents · fopen/fread/fwrite · directorios · CSV · JSON en disco.
archivos_basico.php
<?php
$ruta = 'datos/log.txt';

// Escribir — crea o sobrescribe
file_put_contents($ruta, "Primera línea\n");

// Añadir al final sin borrar
file_put_contents($ruta, "Segunda línea\n", FILE_APPEND | LOCK_EX);

// Leer todo el archivo como string
$contenido = file_get_contents($ruta);
echo $contenido;

// Leer como array de líneas
$lineas = file($ruta, FILE_IGNORE_NEW_LINES | FILE_SKIP_EMPTY_LINES);
foreach ($lineas as $i => $linea) {
    echo "[$i] $linea<br>";
}

// Información del archivo
if (file_exists($ruta)) {
    echo "Tamaño: "      . filesize($ruta) . " bytes\n";
    echo "Modificado: " . date("Y-m-d H:i", filemtime($ruta)) . "\n";
    echo "¿Escribible?: " . (is_writable($ruta) ? "Sí" : "No") . "\n";
}

// Copiar, mover y eliminar
copy($ruta, 'datos/log_backup.txt');
rename('datos/log_backup.txt', 'datos/log_old.txt');
unlink('datos/log_old.txt');
?>
▶ Salida
[0] Primera línea  |  [1] Segunda línea
Tamaño: 30 bytes  |  Modificado: 2024-01-15 10:30
FunciónQué hace
file_get_contents()Lee todo el archivo como string
file_put_contents()Escribe string en archivo (crea o sobrescribe)
file()Lee archivo como array de líneas
file_exists()Comprueba si existe el archivo o directorio
filesize()Tamaño en bytes

ℹ️ Usa fopen() cuando necesites control preciso: leer línea a línea sin cargar todo en memoria, posicionarte en un punto del archivo, o leer y escribir al mismo tiempo.
fopen_avanzado.php
<?php
// Modos de apertura
// "r"  → solo lectura, puntero al inicio
// "w"  → escritura, borra contenido, crea si no existe
// "a"  → escritura al final (append), crea si no existe
// "r+" → lectura y escritura, puntero al inicio
// "x"  → crea nuevo archivo, error si ya existe

// 1. Escribir línea a línea
$f = fopen('log.txt', 'a');
fwrite($f, date('Y-m-d H:i:s') . " — Evento registrado\n");
fclose($f);  // siempre cerrar

// 2. Leer línea a línea (ideal para archivos grandes)
$f = fopen('log.txt', 'r');
while (!feof($f)) {           // feof = fin de archivo
    $linea = fgets($f);       // lee una línea
    if ($linea !== false) {
        echo htmlspecialchars($linea) . "<br>";
    }
}
fclose($f);

// 3. Bloqueo para escritura concurrente (LOCK_EX)
$f = fopen('datos.txt', 'a');
if (flock($f, LOCK_EX)) {       // bloqueo exclusivo
    fwrite($f, "Datos seguros\n");
    flock($f, LOCK_UN);          // liberar bloqueo
}
fclose($f);

// 4. Posicionar el puntero
$f = fopen('datos.txt', 'r');
fseek($f, 10);                   // ir al byte 10
echo ftell($f);                   // posición actual: 10
echo fread($f, 5);                // leer 5 bytes desde pos 10
rewind($f);                       // volver al inicio
fclose($f);
?>
▶ Flujo fopen
fopen() → fwrite()/fgets()/fread() → fclose()
⚠️ Siempre cerrar con fclose() para liberar el recurso
directorios.php
<?php
// Crear directorio (0755 = rwxr-xr-x, true = recursivo)
mkdir('uploads/imagenes/2024', 0755, true);

// Listar contenido de un directorio
$archivos = scandir('uploads');
foreach ($archivos as $archivo) {
    if ($archivo === '.' || $archivo === '..') continue;
    $ruta = "uploads/$archivo";
    $tipo = is_dir($ruta) ? "📁" : "📄";
    echo "$tipo $archivo<br>";
}

// Glob — buscar archivos por patrón
$imagenes = glob('uploads/*.{jpg,png,webp}', GLOB_BRACE);
foreach ($imagenes as $img) {
    echo basename($img) . " — " . filesize($img) . " bytes<br>";
}

// pathinfo — descomponer una ruta
$info = pathinfo('/var/www/uploads/foto.jpg');
echo $info['dirname'];    // /var/www/uploads
echo $info['basename'];   // foto.jpg
echo $info['filename'];   // foto
echo $info['extension'];  // jpg

// Eliminar directorio (debe estar vacío)
rmdir('uploads/temp');

// Eliminar directorio con contenido (función recursiva)
function borrarDirectorio(string $dir): void {
    foreach (glob("$dir/*") as $item) {
        is_dir($item) ? borrarDirectorio($item) : unlink($item);
    }
    rmdir($dir);
}
?>

csv_json_archivos.php
<?php
// ─── CSV ───────────────────────────────────────

// Escribir CSV
$f = fopen('productos.csv', 'w');
fputcsv($f, ['id', 'nombre', 'precio']);  // cabecera
foreach ([
    [1, 'Laptop', 999.99],
    [2, 'Mouse',  25.00],
] as $fila) {
    fputcsv($f, $fila);
}
fclose($f);

// Leer CSV
$f = fopen('productos.csv', 'r');
$cabecera = fgetcsv($f);  // primera fila = cabecera
while (($fila = fgetcsv($f)) !== false) {
    $item = array_combine($cabecera, $fila);  // asociar cabecera
    echo "{$item['nombre']}: S/{$item['precio']}<br>";
}
fclose($f);

// ─── JSON en disco ─────────────────────────────

// Guardar array como JSON
$config = ['version' => '1.0', 'debug' => false, 'db_host' => 'localhost'];
file_put_contents('config.json', json_encode($config, JSON_PRETTY_PRINT));

// Leer JSON desde disco
$cargado = json_decode(file_get_contents('config.json'), true);
echo $cargado['version'];   // 1.0
echo $cargado['db_host'];  // localhost
?>

Subida de Archivos (Upload)
Manejo seguro de $_FILES con validación de tipo MIME real, tamaño y nombre.
⚠️ Siempre valida el tipo MIME real del archivo con finfo, no solo la extensión. Nunca uses el nombre original del usuario en producción.
subir.php
<?php
if (isset($_FILES['imagen']) && $_FILES['imagen']['error'] === UPLOAD_ERR_OK) {
    $archivo   = $_FILES['imagen'];
    $maxBytes  = 2 * 1024 * 1024;           // 2 MB
    $tiposOk  = ['image/jpeg', 'image/png', 'image/webp'];

    if ($archivo['size'] > $maxBytes) die("❌ Supera 2 MB");

    // Tipo MIME real (no el que dice el navegador)
    $finfo   = new finfo(FILEINFO_MIME_TYPE);
    $mimeReal = $finfo->file($archivo['tmp_name']);
    if (!in_array($mimeReal, $tiposOk, true)) die("❌ Tipo no permitido");

    // Nombre seguro aleatorio
    $ext  = strtolower(pathinfo($archivo['name'], PATHINFO_EXTENSION));
    $nombre = bin2hex(random_bytes(16)) . '.' . $ext;
    $destino = __DIR__ . '/uploads/' . $nombre;

    if (move_uploaded_file($archivo['tmp_name'], $destino)) {
        echo "✅ Guardado como: $nombre";
    }
}
?>

✅ Guardado como: a3f8c1d2e4b60f9a1c2d3e4f5a6b7c8d.jpg
