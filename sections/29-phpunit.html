Modulo 21

Testing con PHPUnit

Escribe tests automatizados para garantizar la calidad de tu código, detectar errores temprano y refactorizar con confianza.

1
Que es PHPUnit
El framework de testing unitario mas usado en PHP. Verifica que tu codigo funciona correctamente en cada cambio.

PHPUnit ejecuta fragments de codigo (tests) que comprueban si el resultado de una funcion o clase es el esperado. Si algo cambia y rompe el comportamiento, el test falla y lo detectas al instante.

TipoQue verificaEjemplo
UnitarioUna sola funcion o clase, aisladaTestear que sumar(2,3) devuelve 5
IntegracionVarias piezas trabajando juntasTestear que un Repository guarda y lee de la BD correctamente
FuncionalFlujos completos del usuarioTestear que el login funciona de principio a fin
AspectoCon testsSin tests
MantenibilidadCambios seguros, refactoring rapidoMiedo a tocar codigo, bugs ocultos
ConfianzaSabes que funciona tras cada cambioEsperar a que el usuario reporte errores
DebuggingError localizado al instanteHoras buscando la causa del bug
RegresionNuevos bugs detectados automaticamenteBugs viejos reaparecen sin aviso
DocumentacionLos tests documentan como usar el codigoDepender de comentarios desactualizados
TDD (Test-Driven Development) — Escribir el test ANTES del codigo: 1) Escribir test que falla, 2) Escribir codigo minimo para que pase, 3) Refactorizar.
  1. Red: Escribes un test para una funcionalidad que aun no existe. Falla.
  2. Green: Escribes el codigo mas simple posible para que el test pase.
  3. Refactor: Mejoras el codigo sabiendo que los tests te protegen.
2
Instalacion y Configuracion
Paso a paso para instalar PHPUnit con Composer y configurar tu proyecto.
  1. Instala PHPUnit como dependencia de desarrollo: composer require --dev phpunit/phpunit
  2. Crea el archivo de configuracion phpunit.xml en la raiz del proyecto.
  3. Crea la carpeta tests/ para almacenar los archivos de test.
  4. Ejecuta los tests con ./vendor/bin/phpunit.
Terminal
# Instalar PHPUnit como dependencia de desarrollo
composer require --dev phpunit/phpunit

# Verificar la instalacion

Test Unitarios
La base de todo: clases TestCase, setUp/tearDown y las aserciones mas comunes.
Cada test es un metodo que empieza con test o lleva la anotacion @test. Hereda de PHPUnit\Framework\TestCase.
AsercionQue comprueba
assertEquals($expected, $actual)Que dos valores sean iguales
assertTrue($cond)Que la condicion sea true
assertFalse($cond)Que la condicion sea false
assertNull($value)Que el valor sea null
assertCount($n, $array)Que un array tenga N elementos
assertContains($needle, $haystack)Que un array contenga un valor
expectException($class)Que se lance una excepcion
src/Calculadora.php
<?php
class Calculadora {
    public function sumar(float $a, float $b): float {
        return $a + $b;
    }

    public function restar(float $a, float $b): float {
        return $a - $b;
    }

    public function multiplicar(float $a, float $b): float {
        return $a * $b;
    }

    public function dividir(float $a, float $b): float {
        if ($b == 0) {
            throw new InvalidArgumentException("No se puede dividir por cero");
        }
        return $a / $b;
    }

    public function esPar(int $n): bool {
        return $n % 2 === 0;
    }

    public function factorial(int $n): int {
        if ($n < 0) throw new InvalidArgumentException("No existe factorial negativo");
        if ($n <= 1) return 1;
        $resultado = 1;
        for ($i = 2; $i <= $n; $i++) $resultado *= $i;
        return $resultado;
    }
}
?>
tests/CalculadoraTest.php
<?php
use PHPUnit\Framework\TestCase;
require_once __DIR__ . '/../src/Calculadora.php';

class CalculadoraTest extends TestCase {
    private Calculadora $calc;

    protected function setUp(): void {
        $this->calc = new Calculadora();
    }

    public function testSumar_DosPositivos_RetornaSuma(): void {
        $this->assertEquals(8, $this->calc->sumar(3, 5));
    }

    public function testRestar_DosValores_RetornaDiferencia(): void {
        $this->assertEquals(2, $this->calc->restar(7, 5));
    }

    public function testMultiplicar_DosValores_RetornaProducto(): void {
        $this->assertEquals(15, $this->calc->multiplicar(3, 5));
    }

    public function testDividir_DosValores_RetornaCociente(): void {
        $this->assertEquals(2.5, $this->calc->dividir(5, 2));
    }

    public function testDividir_PorCero_LanzaExcepcion(): void {
        $this->expectException(InvalidArgumentException::class);
        $this->expectExceptionMessage("No se puede dividir por cero");
        $this->calc->dividir(10, 0);
    }

    public function testEsPar_NumeroPar_RetornaTrue(): void {
        $this->assertTrue($this->calc->esPar(4));
    }

    public function testEsPar_NumeroImpar_RetornaFalse(): void {
        $this->assertFalse($this->calc->esPar(7));
    }

    public function testFactorial_Cinco_Retorna120(): void {
        $this->assertEquals(120, $this->calc->factorial(5));
    }

    public function testFactorial_Negativo_LanzaExcepcion(): void {
        $this->expectException(InvalidArgumentException::class);
        $this->calc->factorial(-3);
    }
}
?>

Data Providers
Ejecuta el mismo test con multiples conjuntos de datos sin duplicar codigo.
Un @dataProvider devuelve un array de arrays. Cada sub-array es un conjunto de argumentos que se pasa al test. Si un caso falla, PHPUnit lo muestra por separado.
src/Validador.php
<?php
class Validador {
    public static function esEmailValido(string $email): bool {
        return filter_var($email, FILTER_VALIDATE_EMAIL) !== false;
    }

    public static function esPasswordSeguro(string $pass): bool {
        return strlen($pass) >= 8
            && preg_match('/[A-Z]/', $pass)
            && preg_match('/[0-9]/', $pass);
    }
}
?>
tests/ValidadorTest.php
<?php
use PHPUnit\Framework\TestCase;
require_once __DIR__ . '/../src/Validador.php';

class ValidadorTest extends TestCase {

    /**
     * @dataProvider emailsProvider
     */
    public function testEsEmailValido(string $email, bool $esperado): void {
        $this->assertSame($esperado, Validador::esEmailValido($email));
    }

    public static function emailsProvider(): array {
        return [
            ['usuario@correo.com', true],
            ['nombre.apellido@dominio.org', true],
            ['test+tag@gmail.com', true],
            ['sin_arroba.com', false],
            ['@dominio.com', false],
            ['usuario@', false],
            ['', false],
        ];
    }

    /**
     * @dataProvider passwordsProvider
     */
    public function testEsPasswordSeguro(string $pass, bool $esperado): void {
        $this->assertSame($esperado, Validador::esPasswordSeguro($pass));
    }

    public static function passwordsProvider(): array {
        return [
            ['MiClave123', true],
            ['Abcdef1!', true],
            ['corto1A', false],     // menos de 8 chars
            ['sinmayuscula123', false], // sin mayuscula
            ['SINCIFRAS!!', false],  // sin numero
        ];
    }
}
?>
▶ Salida
OK (12 tests, 12 assertions) — Cada caso del data provider cuenta como un test individual

Mocks y Stubs
Simula dependencias externas (BD, API, email) para aislar el codigo que realmente quieres testear.
TerminoQue esMetodo PHPUnit
StubDevuelve datos predefinidos sin logicamethod()->willReturn()
MockVerifica que un metodo fue llamado con ciertos argumentosexpects()->method()->with()
FakeImplementacion simplificada (ej: BD en memoria)Clase manual
Un stub solo devuelve valores; un mock verifica interacciones. Puedes combinar ambos en el mismo test.

class EmailService {

        return true;

src/Services/NotificationService.php
<?php
class NotificationService {
    public function __construct(private EmailService $email) {}

    public function notificarNuevoUsuario(string $nombre, string $email): bool {
        $asunto = "Bienvenido {$nombre}";
        $cuerpo = "Hola {$nombre}, tu cuenta ha sido creada.";
        return $this->email->enviar($email, $asunto, $cuerpo);
    }
}
?>
tests/NotificationServiceTest.php
<?php
use PHPUnit\Framework\TestCase;
require_once __DIR__ . '/../src/Services/EmailService.php';
require_once __DIR__ . '/../src/Services/NotificationService.php';

class NotificationServiceTest extends TestCase {

    public function testNotificarNuevoUsuario_EnviaEmail(): void {
        // 1. Crear mock del EmailService
        $emailMock = $this->createMock(EmailService::class);

        // 2. Definir que esperamos: que se llame a enviar() una vez
        $emailMock
            ->expects($this->once())
            ->method('enviar')
            ->with(
                'ana@correo.com',
                $this->stringContains('Ana'),
                $this->stringContains('cuenta ha sido creada')
            )
            ->willReturn(true);

        // 3. Inyectar el mock y ejecutar
        $service = new NotificationService($emailMock);
        $resultado = $service->notificarNuevoUsuario('Ana', 'ana@correo.com');

        // 4. Verificar resultado
        $this->assertTrue($resultado);
    }
}
?>

Tests de Integracion
Verifica que tus clases funcionan correctamente con la base de datos y otros componentes reales.
Los tests de integracion son mas lentos que los unitarios. Usa SQLite en memoria para pruebas rapidas sin necesidad de un servidor MySQL.
src/Repositories/UserRepository.php
<?php
class UserRepository {
    public function __construct(private PDO $db) {}

    public function crearTabla(): void {
        $this->db->exec("CREATE TABLE IF NOT EXISTS usuarios (
            id INTEGER PRIMARY KEY AUTOINCREMENT,
            nombre TEXT NOT NULL,
            email TEXT UNIQUE NOT NULL
        )");
    }

    public function insertar(string $nombre, string $email): int {
        $stmt = $this->db->prepare("INSERT INTO usuarios (nombre, email) VALUES (?, ?)");
        $stmt->execute([$nombre, $email]);
        return (int) $this->db->lastInsertId();
    }

    public function buscarPorEmail(string $email): ?array {
        $stmt = $this->db->prepare("SELECT * FROM usuarios WHERE email = ?");
        $stmt->execute([$email]);
        return $stmt->fetch(PDO::FETCH_ASSOC) ?: null;
    }

    public function contar(): int {
        return (int) $this->db->query("SELECT COUNT(*) FROM usuarios")->fetchColumn();
    }
}
?>
tests/UserRepositoryTest.php
<?php
use PHPUnit\Framework\TestCase;
require_once __DIR__ . '/../src/Repositories/UserRepository.php';

class UserRepositoryTest extends TestCase {
    private PDO $db;
    private UserRepository $repo;

    protected function setUp(): void {
        // SQLite en memoria: se destruye al cerrar la conexion
        $this->db = new PDO('sqlite::memory:');
        $this->db->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
        $this->repo = new UserRepository($this->db);
        $this->repo->crearTabla();
    }

    protected function tearDown(): void {
        $this->db = null;
    }

    public function testInsertar_RetornaId(): void {
        $id = $this->repo->insertar('Carlos', 'carlos@test.com');
        $this->assertGreaterThan(0, $id);
    }

    public function testInsertarYBuscarByEmail(): void {
        $this->repo->insertar('Maria', 'maria@test.com');
        $usuario = $this->repo->buscarPorEmail('maria@test.com');

        $this->assertNotNull($usuario);
        $this->assertEquals('Maria', $usuario['nombre']);
    }

    public function testBuscarEmailInexistente_RetornaNull(): void {
        $this->assertNull($this->repo->buscarPorEmail('noexiste@test.com'));
    }

    public function testContar_RecienCreada_RetornaCero(): void {
        $this->assertEquals(0, $this->repo->contar());
    }

    public function testContar_DosRegistros_RetornaDos(): void {
        $this->repo->insertar('Ana', 'ana@test.com');
        $this->repo->insertar('Luis', 'luis@test.com');
        $this->assertEquals(2, $this->repo->contar());
    }
}
?>
▶ Salida
OK (5 tests, 6 assertions) — SQLite en memoria se crea y destruye automaticamente

Buenas Practicas
Convenciones, patron AAA y consejos para escribir tests mantenibles y efectivos.
Nombres descriptivos
// MAL: nombres vagos
public function test1() { ... }
public function testSumar() { ... }

// BIEN: Metodo_Escenario_ResultadoEsperado
public function testSumar_DosNumerosPositivos_RetornaSuma() { ... }
public function testDividir_PorCero_LanzaExcepcion() { ... }
public function testBuscarUsuario_Inexistente_RetornaNull() { ... }
public function testEmail_Vacio_RetornaFalse() { ... }
AAA (Arrange / Act / Assert) — Cada test debe tener tres bloques claros separados por comentarios o lineas en blanco.
Ejemplo patron AAA
public function testCrearPedido_ConItems_RetornaTotal(): void {
    // Arrange — preparar datos y objetos
    $pedido = new Pedido();
    $pedido->agregarItem('Camisa', 25.00, 2);
    $pedido->agregarItem('Pantalon', 40.00, 1);

    // Act — ejecutar la accion a probar
    $total = $pedido->calcularTotal();

    // Assert — comprobar el resultado
    $this->assertEquals(90.00, $total);
    $this->assertCount(2, $pedido->obtenerItems());
}
