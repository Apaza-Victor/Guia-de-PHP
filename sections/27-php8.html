Novedades de PHP 8.x

Enums, Readonly, Fibers, Named Arguments, Match, Null Safe y tipos avanzados: todo lo que aportaron PHP 8.0 a 8.2.

1
Enums (PHP 8.1)
Tipos enumerados para definir conjuntos finitos de valores constantes con comportamiento propio.
enum.php
<?php
// Enum simple — cada caso es una unica instancia de la clase
enum Color {
    case Rojo;
    case Verde;
    case Azul;
}

$c = Color::Rojo;

match ($c) {
    Color::Rojo  => echo "Es rojo\n",
    Color::Verde => echo "Es verde\n",
    Color::Azul  => echo "Es azul\n",
};
?>
enum-backed.php
<?php
// Backed enums: cada caso tiene un valor string o int
enum Estado: string {
    case Pendiente  = 'pendiente';
    case Enviado    = 'enviado';
    case Entregado  = 'entregado';
    case Cancelado  = 'cancelado';
}

// Obtener el valor almacenado
echo Estado::Enviado->value;   // enviado
echo Estado::Enviado->name;    // Enviado

// Crear desde un valor (ideal para BD)
$estado = Estado::from('enviado');

// Buscar sin lanzar excepcion (devuelve null)
$buscado = Estado::tryFrom('inexistente');  // null

// Enum con interfaz
enum Estado: string implements ColorInterfaz {
    case Pendiente = 'pendiente';
    case Entregado = 'entregado';

    public function colorHex(): string {
        return match ($this) {
            self::Pendiente => '#f39c12',
            self::Entregado => '#27ae60',
        };
    }
}
?>
EstadoPedido.php
<?php
enum EstadoPedido: int {
    case Creado     = 0;
    case Procesando = 1;
    case Enviado    = 2;
    case Entregado  = 3;
    case Cancelado  = 99;

    public function label(): string {
        return match ($this) {
            self::Creado     => 'Creado',
            self::Procesando => 'Procesando pedido',
            self::Enviado    => 'Enviado al cliente',
            self::Entregado  => 'Entregado correctamente',
            self::Cancelado  => 'Pedido cancelado',
        };
    }

    public function estaActivo(): bool {
        return $this !== self::Cancelado;
    }
}

$pedido = EstadoPedido::from(2);         // EstadoPedido::Enviado
echo $pedido->label();                // Enviado al cliente
echo $pedido->value;                   // 2
var_dump($pedido->estaActivo());      // bool(true)
?>
Los enums son ideales para reemplazar constantes de clase. Cada caso es un objeto con metodos, lo que permite encapsular logica junto al valor.

Readonly Properties y Classes (PHP 8.1 / 8.2)
Propiedades que solo pueden escribirse una vez, ideal para value objects e inmutabilidad.
readonly.php
<?php
// PHP 8.1 — readonly en propiedades individuales
class Coordenada {
    public function __construct(
        public readonly float $lat,
        public readonly float $lng
    ) {}
}

$punto = new Coordenada(40.4168, -3.7038);
echo $punto->lat;       // 40.4168
// $punto->lat = 0;  // Error: readonly

// PHP 8.2 — clase readonly completa
readonly class Direccion {
    public function __construct(
        public string $calle,
        public string $ciudad,
        public string $codigoPostal
    ) {}
}

$dir = new Direccion('Gran Via 1', 'Madrid', '28013');
// Todas las propiedades son readonly automaticamente
?>
Una propiedad readonly solo puede asignarse una vez (en el constructor). Cualquier intento de reasignacion lanza una excepcion. Son ideales para value objects y DTOs inmutables.

Fibers (PHP 8.1)
Coroutines ligeras para programacion concurrente sin callbacks. Permiten suspender y reanudar ejecucion.
fibers.php
<?php
// Una Fiber es una funcion que puede pausarse y reanudarse
$fiber = new Fiber(function (int $inicio): int {
    echo "Fiber: empiezo con {$inicio}\n";

    $valor = Fiber::suspend('desde fiber');   // pausa aqui
    echo "Fiber: recibi {$valor}\n";

    return $inicio * 10;
});

$resultado = $fiber->start(5);           // Fiber: empiezo con 5
                                // se suspende
echo "Main: fiber suspendio con: {$resultado}\n";  // desde fiber

$fiber->resume(42);              // reanuda con 42
                                // Fiber: recibi 42

echo "Main: fiber devolvio: {$fiber->getReturn()}\n";  // 50
?>
fibers_practico.php
<?php
// Ejemplo practico: scheduler simple de tareas
function tarea(string $nombre, int $ms): Fiber {
    return new Fiber(function() use ($nombre, $ms) {
        echo "[{$nombre}] Inicia\n";
        Fiber::suspend();            // cede control al scheduler
        usleep($ms * 1000);
        echo "[{$nombre}] Termina\n";
    });
}

$tareas = [
    tarea('Tarea A', 200),
    tarea('Tarea B', 100),
    tarea('Tarea C', 300),
];

// Iniciar todas las tareas
foreach ($tareas as $f) $f->start();

// Reanudar todas las tareas
foreach ($tareas as $f) $f->resume();
?>
Las Fibers son coroutines ligeras: se ejecutan en el mismo thread pero pueden pausarse con Fiber::suspend() y reanudarse con resume(). Utiles en bases de datos async, colas de tareas y frameworks como Laravel.

Named Arguments (PHP 8.0)
Pasa argumentos por nombre en vez de por posicion. Ideal para funciones con muchos parametros opcionales.
named-args.php
<?php
// Sin named arguments — debes recordar el orden exacto
array_slice([1,2,3,4,5], 2, 2);  // [3, 4]

// Con named arguments — mas claro y legible
array_slice(
    array: [1,2,3,4,5],
    offset: 2,
    length: 2
);  // [3, 4]

// Funcion personalizada
function crearUsuario(
    string $nombre,
    string $email,
    string $rol = 'user',
    bool   $activo = true,
    string $idioma = 'es'
): array {
    return compact('nombre', 'email', 'rol', 'activo', 'idioma');
}

// Saltar el $rol pero especificar el idioma
$user = crearUsuario(
    nombre: 'Ana',
    email:  'ana@ejemplo.com',
    idioma: 'en'
);
print_r($user);
?>
▶ Salida
Array ( [nombre] => Ana [email] => ana@ejemplo.com [rol] => user [activo] => 1 [idioma] => en )
Los named arguments te permiten omitir valores por defecto sin pasarlos todos en orden. Son especialmente utiles con funciones de UI, configuracion y testing.
5
Constructor Property Promotion (PHP 8.0)
Declara y asigna propiedades directamente en el constructor. Menos boilerplate, mas claridad.
antes-vs-despues.php
<?php
// ANTES de PHP 8.0 — mucho boilerplate
class UsuarioAntes {
    public string $nombre;
    public string $email;
    public string $rol;

    public function __construct(string $nombre, string $email, string $rol = 'user') {
        $this->nombre = $nombre;
        $this->email = $email;
        $this->rol = $rol;
    }
}

// DESPUES de PHP 8.0 — conciso y limpio
class Usuario {
    public function __construct(
        public readonly string $nombre,
        public readonly string $email,
        public readonly string $rol = 'user',
    ) {}
}

$u = new Usuario(nombre: 'Carlos', email: 'carlos@mail.com');
echo $u->nombre;  // Carlos
echo $u->rol;     // user
?>
La promocion no cambia el comportamiento: solo reduce el codigo repetitivo. Puedes combinar con readonly para crear DTOs inmutables en una sola linea.

Match Expression (PHP 8.0)
Alternativa mas potente a switch: compara estrictamente, no tiene fall-through y devuelve valores.
match.php
<?php
// match: compara con ===, no hay fall-through, devuelve valor
function statusCode(int $code): string {
    return match ($code) {
        200, 201  => 'Exito',
        301       => 'Redireccion permanente',
        302       => 'Redireccion temporal',
        400       => 'Peticion incorrecta',
        401       => 'No autenticado',
        403       => 'Prohibido',
        404       => 'No encontrado',
        500       => 'Error interno del servidor',
        default   => 'Codigo desconocido',
    };
}

echo statusCode(200);  // Exito
echo statusCode(404);  // No encontrado

// Comparacion estricta: 0 == "foo" es false con match
$x = match(0) {
    'foo' => 'bar',   // NO coincide (0 !== "foo")
    0     => 'cero',  // SI coincide
};  // "cero"
?>
Caracteristicaswitchmatch
Comparacion== (coercion de tipos)=== (estricta)
Fall-throughSi (requiere break)No (nunca)
Devuelve valorNo directamenteSi (es una expresion)
Sintaxiscase valor:valor =>
ComportamientoFlujo proceduralExpresion funcional

Null Safe Operator ?-> (PHP 8.0)
Encadena llamadas a metodos y propiedades que pueden ser null, sin anidar comprobaciones manuales.
nullsafe.php
<?php
class Pais   { public string $nombre; }
class Ciudad  { public Pais $pais; }
class Direccion { public Ciudad|null $ciudad = null; }
class Usuario {
    public function __construct(public Direccion|null $direccion = null) {}
}

$user = new Usuario();  // sin direccion

// SIN null safe — verbose y propenso a errores
if ($user->direccion !== null) {
    if ($user->direccion->ciudad !== null) {
        echo $user->direccion->ciudad->pais->nombre;
    }
}

// CON null safe — limpio y seguro
echo $user?->direccion?->ciudad?->pais?->nombre ?? 'Desconocido';
// Desconocido (sin excepciones)
?>
Si en cualquier punto de la cadena el valor es null, toda la cadena se corta y devuelve null. Combinar con el operador de fusion nula ?? para proveer un valor por defecto.

Intersection y Union Types (PHP 8.0 / 8.1 / 8.2)
Tipos avanzados: uniones (int|string), intersecciones (A&B) y DNF (8.2) para mayor precision en los tipos.
tipos-avanzados.php
<?php
interface Logger {
    public function log(string $msg): void;
}

interface Cacheable {
    public function getCacheKey(): string;
}

// Union types (PHP 8.0) — el valor puede ser de 2+ tipos
function formatoId(int|string $id): string {
    return "ID: {$id}";
}
formatoId(42);       // OK
formatoId('abc');   // OK

// Intersection types (PHP 8.1) — debe implementar ambas
function registrar(Logger & Cacheable $servicio): void {
    $servicio->log("Registrando en cache: " . $servicio->getCacheKey());
}

// DNF types (PHP 8.2) — combina union e interseccion
function procesar((Logger & Cacheable)|null $svc): void {
    $svc?->log('procesando');
}

// Ejemplo con clase concreta
class AppLogger implements Logger, Cacheable {
    public function log(string $msg): void {
        echo "[LOG] {$msg}\n";
    }
    public function getCacheKey(): string {
        return 'app_logger_v1';
    }
}

registrar(new AppLogger());  // [LOG] Registrando en cache: app_logger_v1
?>
TipoVersionSintaxisSignificado
UnionPHP 8.0int|stringCumple al menos un tipo
IntersectionPHP 8.1A&BCumple todos los tipos
DNFPHP 8.2(A&B)|nullInterseccion + union
Las intersecciones son ideales para dependency injection: exigir que un objeto cumpla multiples contratos sin heredar de una clase base.
